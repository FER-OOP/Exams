Implement the object model for a food delivery system according to the given UML diagram.

The system supports different types of orders and different types of delivery persons. Each order has its own status, base price, delivery distance, and rules for calculating the total price and the estimated delivery time.

In all classes and interfaces, implement the attributes, constructors, and methods exactly as shown in the UML diagram. You may freely add helper methods, but you must not change the given method names, parameter lists, or return types.

NOTE: All classes, interfaces, and enumerations must have public visibility and must be placed in the package hr.fer.oop.

The following components are already provided:

  • enumerations OrderStatus and VehicleType
  • interfaces Trackable and Cancellable
  • the abstract class DeliveryPerson with an implemented constructor and getter methods

These components should not be modified or reimplemented. The remaining classes must be implemented according to the UML diagram and the functionality description.

The following classes need to be implemented:

Functionality description:

The enumeration OrderStatus represents the status of an order, while the enumeration VehicleType represents the type of vehicle used by a delivery person. The interface Trackable defines methods for tracking an order:

  • getEstimatedDeliveryTime() which returns the estimated delivery time in minutes
  • getOrderInfo() which returns a textual description of the order

The interface Cancellable defines the ability to cancel an order.

The abstract class DeliveryPerson represents a delivery person and contains basic information about the delivery person’s name, delivery speed (speedKmh), and vehicleType.

Delivery persons

Different types of delivery persons differ in:

  • the maximum distance they can deliver
  • the way the delivery fee is calculated

The following rules apply to individual types of delivery persons:

  • A BikeCourier can deliver orders up to a maximum distance of 5 km. The delivery speed is 15 km/h, and the delivery fee is calculated as 0.8 * distance.
  • A CarCourier can deliver to any non-negative distance. The delivery speed is 50 km/h, and the delivery fee is calculated as 1.8 * distance + 2.

Orders

The class Order represents a general order. An order may have an assigned delivery person, may change its status throughout its lifecycle, and supports price calculation and delivery time estimation. When an order is created:

  • the status is set to CREATED
  • no delivery person is assigned (null)

The method assignDeliveryPerson(deliveryPerson: DeliveryPerson) assigns a delivery person to the order. Assignment is possible only if:

  • the delivery person is not null
  • the order is not in status CANCELLED
  • the delivery person can deliver the given distance

Order statuses:

Allowed status transitions:

  • CREATED → CONFIRMED
  • CONFIRMED → IN_DELIVERY (only if a delivery person is assigned)

The method confirm() confirms the order:

  • The order can be confirmed only from status CREATED. In that case, the status changes and the method returns true. Otherwise, it returns false.

The method startDelivery() starts the delivery.

  • Starting delivery is successful only if the status is CONFIRMED and a delivery person has been assigned.
  • If successful, the status changes and the method returns true; otherwise, it returns false.

The method completeDelivery() completes the delivery.

  • It is successful only if the status is IN_DELIVERY.
  • If successful, the status changes and the method returns true; otherwise, it returns false.

The method cancel() cancels the order.

  • Cancellation is possible in all states except DELIVERED and CANCELLED
  • If cancellation is possible, the status changes and the method returns true; otherwise, it returns false.

The method getEstimatedDeliveryTime() for regular delivery orders:

  • If no delivery person is assigned, the estimated delivery time is -1
  • Otherwise, the time is calculated as the ratio between the distance (distanceKm) and the delivery person’s speed (speedKmh), be careful to convert from hours to minutes
  • the resulting value is rounded up to the next integer

The method getOrderInfo() returns a textual description of the order that includes: the customer name (customerName), restaurant name (restaurantName) and the current order status (status). Subclasses may extend this description with additional information specific to the order type. The exact output format is not strictly defined, but the description must contain all relevant information. See the execution example for expected content.

FoodOrder

The class FoodOrder represents a standard delivery order.

The total price is calculated as: base price (basePrice) + delivery fee (if a delivery person exists) (deliveryFee) + an additional charge equal to 2 * numberOfMeals

Override getOrderInfo() to include delivery person name (or NONE) and number of meals.

PickupOrder

The class PickupOrder represents an order picked up by the customer (no delivery). Rules:

  • assignDeliveryPerson(...) always returns false
  • getEstimatedDeliveryTime() returns 0
  • total price = basePrice
  • override getOrderInfo() so it always shows that no delivery person is assigned (NONE), regardless of state

Example usage:

// Creating orders
Order o1 = new FoodOrder("Ana", "Pizza House", 18.0, 4.5, 3);
Order o2 = new PickupOrder("Iva", "Burger Bar", 12.0);

// Creating couriers
DeliveryPerson bike = new BikeCourier("Filip");
DeliveryPerson car = new CarCourier("Petra");

// Assigning couriers
System.out.println(o1.assignDeliveryPerson(bike)); 
System.out.println(o2.assignDeliveryPerson(car)); 

// Changing status and starting delivery
o1.confirm();
o1.startDelivery();

// Order info
System.out.println(o1.getOrderInfo()); 		 
System.out.println("Estimated time: " + o1.getEstimatedDeliveryTime()); 
System.out.println("Total price: " + o1.getTotalPrice());  

System.out.println();

// Pickup order
System.out.println(o2.getOrderInfo());
System.out.println("Estimated time: " + o2.getEstimatedDeliveryTime());  
System.out.println("Total price: " + o2.getTotalPrice());
