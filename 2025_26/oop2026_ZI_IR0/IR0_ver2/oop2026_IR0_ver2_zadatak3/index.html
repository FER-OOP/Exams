Potrebno je implementirati sustav za vođenje osobne kolekcije vinil ploča. Ploče se ne čuvaju izravno, već se slažu u kutije.

U zadatku je potrebno napisati klase koje opisuju skladište (Storage) i iznimku (StorageException) prema priloženom dijagramu klasa. Klasa kutija (Box) je djelomično implementirana i potrebno je ispravno parametrizirati. Ostale klase (Vinyl, Album i Single) priložene su uz zadatak i ne mijenjate ih.

Sve klase su public i nalaze se u paketu hr.fer.oop.

Priložene klase (ne mijenjate ih):

  • Vinyl — osnovna klasa za ploče (artist, title, price).
  • Album i Single — nasljeđuju Vinyl.

Klasa Box (djelomično napisana): kutija u koju se slažu ploče. Klasa vam je dana gotova, ali bez parametrizacije. Klasa treba biti parametrizirana tako da kutija može sadržavati ploče (Vinyl) ili njihove specijalizirane oblike (npr. Album i Single), pri čemu svaka kutija u jednom trenutku sadrži samo jedan tip elemenata. Metoda totalValue() vraća zbroj cijena svih ploča u kutiji.

Klasa StorageException (pišete je): provjeravana iznimka koju baca skladište u slučaju pokušaja dodavanja kutije s već postojećim nazivom ili dodavanja ploče u nepostojeću kutiju (detaljnije opisano u klasi Storage).

Klasa Storage (pišete je): upravlja kolekcijom kutija.

  • kutije koje pohranjuju ploče (Vinyl) se čuvaju u mapi gdje je ključ naziv kutije.
  • addBox(String name, Box<Vinyl> box) — registrira kutiju pod zadanim nazivom. Ako kutija s istim nazivom već postoji, baca StorageException s opisnom porukom. Točan tekst poruke nije propisan, ali poruka ne smije biti izostavljena.
  • store(String boxName, Vinyl vinyl) — stavlja ploču u kutiju zadanog naziva. Ako kutija ne postoji, baca StorageException.
  • getMostExpensiveBoxName() — vraća naziv kutije s najvećom ukupnom vrijednošću (totalValue()). Možete pretpostaviti da skladište nije prazno i da postoji samo jedna takva kutija.
  • findByArtist(String artist) — vraća sve ploče zadanog izvođača iz svih kutija, u protivnom praznu listu.
  • getAllVinylTitlesAlphabetically() — vraća naslove ploče iz svih kutija, sortirane abecedno, u protivnom praznu listu.

Napomena: Povratne vrijednosti metoda, kao i ostali detalji, dostupni su na priloženom UML dijagramu. Obratite pozornost na UML dijagram!

Primjer korištenja:

Storage storage = new Storage();

        Box<Vinyl> rockBox = new Box<>();
        Box<Vinyl> jazzBox = new Box<>();

        try {
        	storage.addBox("rock", rockBox);
            storage.addBox("jazz", jazzBox);
            storage.addBox("jazz", jazzBox);	// ERROR (already exists Key)
        } catch (StorageException e) {
            System.err.println("Error: " + e.getMessage());
        }
        
        try {
        	storage.store("rock", new Album("Beatles", "Abbey Road", 25.0, 17));
            storage.store("rock", new Single("Beatles", "Hey Jude", 10.0, "Revolution"));
            storage.store("jazz", new Album("Miles Davis", "Kind of Blue", 30.0, 5));
            storage.store("jazz", new Album("John Coltrane", "A Love Supreme", 28.0, 4));
            storage.store("pop", new Single("ABBA", "Waterloo", 5.0, "Watch Out")); // ERROR (NOT found Key)
        } catch (StorageException e) {
            System.err.println("Error: " + e.getMessage());
        }

        System.out.println("Most expensive box: " + storage.getMostExpensiveBoxName()); 

        System.out.println("\n--- The Beatles vinyls ---");
        for (Vinyl v : storage.findByArtist("Beatles")) {
            System.out.println(v);
        }

        System.out.println("\n--- All vinyl titles alphabetically ---");
        for (String v : storage.getAllVinylTitlesAlphabetically()) {
            System.out.println(v);
        }
