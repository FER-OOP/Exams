Your task is to program the flow of a game inspired by the board game Risk, where players attempt to conquer territories and take over the world. A concrete class GameObject, which represents all entities in the game, and a concrete class Player, which represents all players in the board game, are provided along with a Main class which should be read to understand how all of the types described below are used. You need to complete the code of the concrete classes Territory, Soldier and Tank, as well as write the types AttackUnit and MovableUnit, for which you need to decide whether they should be interfaces or abstract classes. All concrete classes have GameObject as a superclass, but not necessarily as their direct superclass.

NOTE: The classes GameObject and Player must not be modified for correct grading of the solution.

Objects of type GameObject have a name (name) and a defense level (defenseLevel) of type int which are set when the object is created. The current defense level can be retrieved by calling getDefenseLevel(), while the defense level can be decreased by calling weaken(int amount). The defense level cannot become negative.

Objects of type Player represent players in the strategy game and extend GameObject. Each player tracks the number of conquered territories (territoriesOwned) which starts at 0. The number of conquered territories can be increased by calling void conquerTerritory(), while the current value can be retrieved by calling getTerritoriesOwned().

The type AttackUnit represents all units that can participate in combat. All concrete classes Territory, Soldier and Tank are of this type and implement methods:

  • void attack(Territory territory, int territoryRoll) - describes the way they attack their enemies, and
  • void defend() - describes the way they defend from their enemied.

The type MovableUnit represents all player units that can move around the board. Only Soldier and Tank can move. Objects of this type implement the following methods:

  • int getFieldsMoved() - retrieves the number of fields moved,
  • void addFields(int fields) - adds the desired number of fields upon moving,
  • boolean canMove() - returns whether the unit is allowed to move based on conquered territories,
  • void move(int fields) - moves the unit if the condition canMove() is met.

Objects of type Soldier represent infantry units. A soldier can only move when strong enough, i.e. when controlling enough territories.

  • boolean canMove() – returns true if the soldier controls at least 2 territories
  • void move(int fields) – moves the soldier by the given number of fields if canMove() is true,
  • void attack(Territory territory, int territoryRoll) – rolls once (1–12) using a random number method; if the result is greater than territoryRoll, the territory is weakened by 5 and the soldier conquers it; if the result is equal, the one with the lower defenseLevel is weakened by 5; otherwise the soldier is weakened by 5
  • void defend() – increases defense level by 3

Objects of type Tank represent armored units, another type of player in the game. A tank is more powerful than a soldier and can move with just one conquered territory, but its movement costs defense due to the vehicle's weight.

  • boolean canMove() – returns true if the tank controls at least 1 territory
  • void move(int fields) – if it can move, it moves the tank by fields + 2 due to engine power and decreases own defense by 2 due to the vehicle's weight
  • void attack(Territory territory, int territoryRoll) – rolls once (1–12) using a random number method with a +3 bonus (maximum 12); if the result is greater than or equal to territoryRoll, the territory is weakened by 15 and the tank conquers it; otherwise the tank is weakened by 1
  • void defend() – increases defense level by 8 as tanks are heavily armored

Objects of type Territory represent territories on the board — they are fixed parts of the board that can attack and defend. Think of them as base stations defending a region. Each territory can raise its walls once by calling defend(), after which it is protected from the next attack. Once the protection is used, the walls come down and the territory is vulnerable again.

  • boolean isReinforced() – returns whether the territory is currently protected by raised walls
  • void weaken(int amount) – if the territory is reinforced (isReinforced() == true), the attack is ignored and the walls come down (protection is consumed); otherwise the defense level is decreased by the given amount
  • void attack(Territory territory, int territoryRoll) – rolls once (1–12) using a random number method; if the result is greater than territoryRoll, the target territory is weakened by 5; if the result is equal, the one with the lower defenseLevel is weakened by 5; otherwise this territory is weakened by 3
  • void defend() – increases defense level by 5 and raises the walls (sets reinforced to true)

The concrete classes have one constructor each, and an example of how they are instantiated is shown in the provided main method in the Main class:

Territory england = new Territory("England", 100);  // name, defenseLevel
Territory france  = new Territory("France", 80);
Soldier s         = new Soldier("Infantry", 40, 0); // name, defenseLevel, fieldsMoved
Tank tank         = new Tank("Heavy Tank", 80, 0);  // name, defenseLevel, fieldsMoved
