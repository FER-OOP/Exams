U stablu direktorija nalaze se brojne datoteke različitih tipova organizirane u poddirektorije. Potrebno je obići stablo direktorija te prikupiti informacije isključivo o tekstualnim datotekama (datotekama s ekstenzijom .txt). Pri tome je potrebno pretražiti samo one direktorije čiji naziv sadrži niz txt, dok ostale direktorije (zajedno s njihovim poddirektorijima) treba u potpunosti preskočiti.

Za svaku tekstualnu datoteku koja se nalazi u odgovarajućem direktoriju potrebno je prebrojati ukupan broj takvih datoteka, izračunati njihovu ukupnu veličinu (u bajtovima) te zabilježiti nazive direktorija u kojima su pronađene tekstualne datoteke.

Za obilazak stabla direktorija potrebno je napisati klasu TxtSearchVisitor koja (izravno ili neizravno) implementira sučelje FileVisitor.

Klasa TxtSearchVisitor mora implementirati sljedeće javne metode:

  • int getTotalTxtFiles() - vraća ukupan broj pronađenih tekstualnih datoteka (datoteka s ekstenzijom .txt),
  • long getTotalSize() - vraća ukupnu veličinu svih pronađenih tekstualnih datoteka izraženu u bajtovima,
  • Collection<String> getDirectories() - vraća nazive direktorija u kojima su pronađene tekstualne datoteke. Nazivi direktorija moraju biti jedinstveni, svaki naziv smije se pojaviti samo jednom. Redoslijed naziva nije bitan. Pogledati primjer.

Unutar dozvoljenih direktorija potrebno je u obzir uzeti samo one dokumente koje završavaju ekstenzijom .txt.

Potrebno je i dopuniti klasu Main koja je djelomično napisana. Potrebno je napisati statičku metodu

void callVisitor(Path startDir, FileVisitor<Path> visitor)

u kojoj se pomoću visitora obilazi stablo direktorija i računaju tražene vrijednosti. Ako prilikom poziva visitora dođe do iznimke, potrebno je pozvati metodu printStackTrace() odgovarajuće klase iznimke.

Sve klase trebaju biti u paketu hr.fer.oop.

VAŽNO: Za rad s datotekama obavezno koristiti klasu java.nio.file.Path !

VAŽNO: Startni (prvi) direktorij u nazivu sadrži niz txt te njega nije potrebno dodatno provjeravati. Potrebno je promatrati poddirektorije koji se nalaze u njemu. Pogledati primjer (startni direktorij je "src/main/resources/txtExercise/").

VAŽNO: Prilikom obilaska stabla direktorija potrebno je obraditi samo one direktorije čiji naziv sadrži niz txt. Ako naziv direktorija ne sadrži niz txt, taj direktorij i sve njegove poddirektorije potrebno je preskočiti vraćanjem odgovarajuće vrijednost iz enumeracije koja kontrolira tijek obilaska datotečnog sustava.

VAŽNO: Možete pretpostaviti da su sve datoteke ispravno formatirane te da neće doći do pogreške ili iznimke prilikom obilaska stabla direktorija.

Primjer pokretanja:

Primjer poddirektorija u src/main/resources/txtExercise/:
-- Diroop		// Ne sadrži u nazivu `txt`
-- txtDIR1		// POHRANITI NAZIV
------ 1.txt
------ txtDIR1		// POHRANITI NAZIV
---------- 2.txt
------ txtPodDIR1	// Ne posjeduje `.txt` datoteke
---------- txtdir1	// POHRANITI NAZIV
------------ 3.txt
-- txtDIR2		// Ne posjeduje `.txt` datoteke

	Path startDir = Path.of("src/main/resources/txtExercise/");
    	TxtSearchVisitor visitor = new TxtSearchVisitor();
    	
    	callVisitor(startDir, visitor);
    	
    	System.out.println("Total .txt files: " + visitor.getTotalTxtFiles());
    	System.out.println("Total size (bytes): " + visitor.getTotalSize());
    	
    	System.out.println("Directories: ");
    	Collection<String> directories = visitor.getDirectories();
    	for (String dir : directories) {
    		System.out.println(dir);
    	}
