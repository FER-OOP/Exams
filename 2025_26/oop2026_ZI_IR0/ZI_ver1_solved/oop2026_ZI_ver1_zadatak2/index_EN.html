Static method filterAndSortCollection

The input arguments are: 1) a collection of music records, 2) a predicate of music records and 3) a comparator of music records. The method should return an output collection of music records representing the filtered and sorted input collection. Filtering should be done so that only music records satisfying the given predicate remain in the output collection. Sorting should be done using the given comparator, and the top 5 music records should be returned.

Static method totalListeningTimeMinutes

This method takes a stream of music records and returns the total listening time of all songs expressed in minutes as a value of type long. The total listening time of an individual song is calculated as the song duration multiplied by the listen count.

Static method songsByGenre

This method takes a collection of music records and returns a stream of strings in the format "Genre: Song Name" for each record in the collection. Genres are sorted in ascending order, and each line represents one of the songs belonging to the genre until all of them are listed.

Static method topFiveArtists

This method takes a collection of music records and returns a stream of the names of the top 5 artists with the highest total listen count in descending order.
