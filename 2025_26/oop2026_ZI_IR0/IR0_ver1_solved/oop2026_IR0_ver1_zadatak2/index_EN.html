The directory tree contains numerous files of various types organized into subdirectories. You need to traverse the directory tree and collect information exclusively about text files (files with the .txt extension). When doing so, search only those directories whose name contains the substring txt, while all other directories (together with their subdirectories) must be skipped entirely.

For each text file found in an eligible directory, you need to count the total number of such files, compute their total size (in bytes), and record the names of the directories in which the text files were found.

To traverse the directory tree, you need to write a class TxtSearchVisitor that (directly or indirectly) implements the FileVisitor interface.

The TxtSearchVisitor class must implement the following public methods:

  • int getTotalTxtFiles() — returns the total number of text files found (files with the .txt extension),
  • long getTotalSize() — returns the total size of all text files found, expressed in bytes,
  • Collection<String> getDirectories() — returns the names of the directories in which text files were found. The directory names must be unique; each name may appear only once. The order of the names does not matter. See the example.

Within the eligible directories, take into account only those files that end with the .txt extension.

You also need to complete the Main class, which is partially written. You need to implement the static method

void callVisitor(Path startDir, FileVisitor<Path> visitor)

in which the visitor traverses the directory tree and computes the required values. If an exception occurs while invoking the visitor, the printStackTrace() method of the corresponding exception class should be called.

All classes should be in the package hr.fer.oop.

IMPORTANT: For working with files, you must use the java.nio.file.Path class!

IMPORTANT: The initial (first) directory contains the string txt in its name, so it does not need to be checked. Its subdirectories must be examined. See the example (the start directory is "src/main/resources/txtExercise/").

IMPORTANT: When traversing the directory tree, process only those directories whose name contains the substring txt. If a directory's name does not contain txt, that directory and all of its subdirectories must be skipped by returning the appropriate value from an enumeration that controls the traversal of the file system.

IMPORTANT: You may assume that all files are correctly formatted and that no errors or exceptions will occur while traversing the directory tree.

	Path startDir = Path.of("src/main/resources/txtExercise/");
	TxtSearchVisitor visitor = new TxtSearchVisitor();

	callVisitor(startDir, visitor);

	System.out.println("Total .txt files: " + visitor.getTotalTxtFiles());
	System.out.println("Total size (bytes): " + visitor.getTotalSize());

	System.out.println("Directories: ");
	Collection<String> directories = visitor.getDirectories();
