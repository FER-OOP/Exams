Your task is to implement characters from a video game, where the main player tries to survive in a world full of infected enemies. Concrete classes Character, which represents all characters in the game, and Enemy, which represents all infected enemies, are provided along with a Main class which should be read to understand how all of the types described below are used. You need to complete the code in the concrete classes Runner, Stalker and MainCharacter, as well as write the types CombatUnit and StealthUnit, for which you need to decide whether they should be interfaces or abstract classes. All concrete classes have either Character or Enemy as a superclass, but not necessarily as their direct superclass.

NOTE: The classes Character and Enemy must not be modified for correct grading of the solution.

Objects of type Character represent all characters in the game. Each character possesses a name (name) and health (health) of type int which are set when the object is created. The current health can be retrieved by calling getHealth(), and the name by calling getName(). Health cannot become negative and is decreased by the given amount by calling void loseHealth(int amount).

Objects of type Enemy represent infected enemies and are therefore of type Character — the infected were once human. Each enemy has a name (type). Each enemy can bite the attacked character by calling void bite(Character character) — a bite increases the bite counter (bittenTurns) on the attacked character by 1.

The type CombatUnit represents all units that can actively participate in combat. Objects of this type have the following method:

  • void fight(Character character) – describes how the character of this type fights with their opponents

The type StealthUnit represents enemies that rely on stealth. Objects of this type have the following methods:

  • int getStealthLevel() – returns the current stealth level
  • boolean isStealthy() – returns whether the unit is currently in stealth
  • void hide() – defines the hiding behavior which is unique to each instance of this type
  • void toggleStealth() – toggles the stealth state; if true it becomes false and vice versa

Objects of type MainCharacter represent the main player. The main player can craft medicine and attack enemies.

  • int getBittenTurns() – returns the current bite counter
  • void increaseBittenTurns(int amount) – increases the bite counter to the given amount
  • void craftMedkit() – if bittenTurns > 0, decreases bittenTurns by 1 and fails to heal; otherwise increases health by 15
  • void fight(Character character) – decreases own health by 2 due to fatigue; if attacking a Runner, decreases its health by 20; if attacking a Stalker, decreases its health by 10; otherwise decreases the target's health by 5

Objects of type Stalker represent infected that hunt from the shadows and have a stealth level (stealthLevel). The higher the stealth level, the more destructive the attack. It bites its opponent only if its in hiding.

  • int getStealthLevel() – returns the current stealth level which the Stalker stores internally as a field
  • void hide() – increases the stealth level by 1
  • void fight(Character character) – if the Stalker is stealthy (isStealthy() == true), the attacked character's health is decreased by stealthLevel * 10 and the Stalker bites its opponent, increasing the number of bites on the attacked by one; otherwise the attacked character's health is decreased by 10; after the attack toggleStealth() is called, either hiding or revealing the Stalker
  • void loseHealth(int amount) – if the Stalker is stealthy, it takes no damage as is protected by stealth; otherwise it loses the given amount

Objects of type Runner represent aggressive infected that charge toward their victim. A Runner always attacks its opponent by biting it and can enter a rage state by calling rage(), after which its attacks are more destructive.

  • void rage() – puts the Runner into a rage state
  • void bite(Character character) – increases bittenTurns on the attacked character by 2 if in a rage state; otherwise behaves the same as the parent class
  • void fight(Character character) – attacks by biting its opponent; decreases own health by 2 due to exhaustion and the attacked character's health by 10; in a rage state decreases its own health by 4 and the attacked character's health by 20

The concrete classes have one constructor each, and an example of how they are instantiated is shown in the provided main method in the Main class:

Runner runner       = new Runner("Runner", 40);        // type, health
Stalker stalker     = new Stalker("Stalker", 50, 2);   // type, health, stealthLevel
MainCharacter ellie = new MainCharacter("Ellie", 100); // name, health

NOTE: All classes and interfaces must have their visibility set to public and be located in the package hr.fer.oop.
