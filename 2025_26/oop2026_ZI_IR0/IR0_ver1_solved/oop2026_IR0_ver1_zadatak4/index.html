Vaš je zadatak modelirati program koji predstavlja servis za slušanje glazbe, potrebno je nadopuniti programski kod klasa MusicRecord i MusicLambdas. Klasa MusicRecord sadrži zapise o slušanju pjesama, a sastoji se od 6 atributa minimalne vidljivosti:

  • String songName - predstavlja naziv pjesme,
  • String artistName - predstavlja naziv izvođača,
  • String genre - predstavlja glazbeni žanr pjesme,
  • int durationSeconds - predstavlja trajanje pjesme izraženo u sekundama,
  • int listenCount - predstavlja broj slušanja pjesme i
  • LocalDate lastPlayed - predstavlja datum posljednjeg slušanja pjesme.

NAPOMENE: Sve statičke metode potrebno je implementirati kao lambda izraze koristeći Java Stream API (tj. kolekcijske tokove). Pri implementaciji nije potrebno hvatati niti obrađivati iznimke. Klasa MusicLambdas treba se nalaziti u paketu hr.fer.oop, a ona i sve statičke metode trebaju imati maksimalnu vidljivost.

Statička metoda filterAndSortCollection

Ulazni argumenti su: 1) kolekcija glazbenih zapisa, 2) predikat glazbenog zapisa i 3) komparator glazbenog zapisa. Potrebno je vratiti izlaznu kolekciju glazbenih zapisa koja predstavlja filtriranu i sortiranu ulaznu kolekciju glazbenih zapisa. Filtriranje ulazne kolekcije potrebno je napraviti na način da u izlaznoj kolekciji preostanu samo glazbeni zapisi koji zadovoljavaju predani predikat. Sortiranje izlazne kolekcije potrebno je ostvariti predanim komparatorom te vratiti prvih 5 glazbenih zapisa.

Statička metoda totalListeningTimeMinutes

Ova metoda prima tok glazbenih zapisa i vraća ukupno vrijeme slušanja svih pjesama izraženo u minutama kao vrijednost tipa long. Ukupno vrijeme slušanja pojedine pjesme računa se formulom trajanje pojedine pjesme pomnoženo s brojem slušanja.

Statička metoda songsByGenre

Ova metoda prima kolekciju glazbenih zapisa i vraća tok nizova znakova oblika "Žanr: Naziv pjesme" za svaki zapis u kolekciji. Žanrovi su sortirani uzlazno, a za svaki žanr se ispisuje onoliko redova koliko ima njegovih pjesama.

Statička metoda topFiveArtists

Ova metoda prima kolekciju glazbenih zapisa i vraća tok imena 5 izvođača s najvećim ukupnim brojem slušanja, sortirano silazno prema broju slušanja.

Primjer korištenja klase MusicLambdas i statičkih atributa filterAndSortCollection, totalListeningTimeMinutes, topFiveArtists i songsByGenre koje treba implementirati su prikazani u klasi Main:
