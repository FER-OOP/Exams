Vaš zadatak je isprogramirati tijek društvene igre gdje igrači pokušavaju osvajati teritorije i preuzeti svijet. U zadatku su dane konkretne klase GameObject, koja predstavlja sve entitete u igri, i Player, koja predstavlja sve igrače u društvenoj igri, kao i klasa Main koju je potrebno pročitati kako bi se vidjelo na koji način se koriste sve od dolje objašnjenih tipova. Potrebno je nadopuniti konkretne klase Territory, Soldier i Tank te napisati tipove AttackUnit i MovableUnit za koje je potrebno odlučiti trebaju li biti sučelja ili apstraktne klase. Sve konkretne klase imaju klasu GameObject kao nadklasu, ali ne nužno kao svoju direktnu nadklasu.

NAPOMENA: Klase GameObject i Player nije dozvoljeno mijenjati radi ispravnog bodovanja rješenja.

Objekti tipa GameObject imaju naziv (name) i razinu obrane (defenseLevel) tipa int koji se postavljaju prilikom stvaranja objekta. Trenutna razina obrane može se dohvatiti pozivanjem metode getDefenseLevel(), dok se razina obrane može smanjiti pozivanjem metode weaken(int amount). Razina obrane objekta ne može postati negativna.

Objekti tipa Player predstavljaju igrače u strateškoj igri te su stoga tipa GameObject. Svaki igrač prati broj osvojenih teritorija (territoriesOwned) koji na početku iznosi 0. Broj osvojenih teritorija tipa int može se povećati osvajanjem novih teritorija pozivanjem metode void conquerTerritory(), dok se trenutno stanje može dohvatiti pozivanjem metode getTerritoriesOwned().

Tip AttackUnit predstavlja sve jedinice koje mogu sudjelovati u borbi. Sve konkretne klase Territory, Soldier i Tank su ovog tipa i imaju sljedeće metode:

  • void attack(Territory territory, int territoryRoll) - opisuje na koji način se bori s protivnicima i
  • void defend() - opisuje na koji način se brani od svojih protivnika.

Tip MovableUnit predstavlja sve igrače jedinice koje se mogu kretati po ploči. Po ploči se mogu kretati entiteti tipa Soldier i Tank. Objekti ovog tipa imaju sljedeće metode:

  • int getFieldsMoved() - mogu saznati broj prijeđenih polja,
  • void addFields(int fields) - dodaje željeni broj polja,
  • boolean canMove() - vraća je li jedinici dopušteno kretanje na temelju osvojenih teritorija,
  • void move(int fields) - pomiče jedinicu ukoliko je uvjet iz canMove() ispunjen.

Objekti tipa Soldier predstavljaju pješačke jedinice. Vojnik se može kretati tek kada je dovoljno jak, tj. kada kontrolira dovoljno teritorija.

  • boolean canMove() – vraća true ako vojnik kontrolira barem 2 teritorija
  • void move(int fields) – pomiče vojnika za zadani broj polja ako je canMove() istinit,
  • void attack(Territory territory, int territoryRoll) – baca kockicu jednom (1–12) koristeći metodu za nasumično biranje broja; ako je rezultat veći od territoryRoll, teritorij se oslabljuje za 5 i vojnik osvaja teritorij; ako je rezultat jednak, gleda se koji od dva entiteta ima veći defenseLevel i slabiji se oslabljuje za 5; u suprotnom se vojnik oslabljuje za 5
  • void defend() – povećava razinu obrane za 3

Objekti tipa Tank predstavljaju oklopne jedinice koji su također igrači. Tenk je moćnija jedinica od vojnika te se može kretati već s jednim osvojenim teritorijem, ali njegovo kretanje troši obranu zbog težine vozila.

  • boolean canMove() – vraća true ako tenk kontrolira barem 1 teritorij
  • void move(int fields) – ako se može pomaknuti, provjerava se pozivom metode canMove(), pomiče se za fields + 2 polja zbog snage motora i smanjuje vlastitu razinu obrane za 2 zbog težine vozila
  • void attack(Territory territory, int territoryRoll) – baca kockicu jednom (1–12) koristeći metodu za nasumično biranje broja, s bonusom +3 (maksimalni broj koji može imati je 12); ako je rezultat veći ili jednak territoryRoll, teritorij se oslabljuje za 15 i tenk osvaja teritorij; u suprotnom se tenk oslabljuje za 1
  • void defend() – povećava razinu obrane za 8 jer su tenkovi jako oklopljeni

Objekti tipa Territory predstavljaju teritorije na ploči, oni su nepomični dijelovi ploče koji mogu napadati i braniti se. Zamislite ih kao bazne stanice za obranu pojedinog teritorija. Svaki teritorij može jednom zatvoriti bedeme pozivom metode defend(), nakon čega je zaštićen od sljedećeg napada. Nakon što je zaštita iskorištena, bedemi se otvaraju i teritorij je ponovno ranjiv.

  • boolean isReinforced() – vraća je li teritorij trenutno zaštićen zatvorenim bedemima
  • void weaken(int amount) – ako je teritorij zaštićen (isReinforced() == true), napad se zanemaruje i bedemi se otvaraju (zaštita se troši); u suprotnom se razina obrane smanjuje za zadani iznos
  • void attack(Territory territory, int territoryRoll) – baca kockicu jednom (1–12) koristeći metodu za nasumično biranje broja; ako je rezultat veći od territoryRoll, ciljni teritorij se oslabljuje za 5; ako je rezultat jednak, gleda se koji od dva entiteta ima veći defenseLevel i slabiji se oslabljuje za 5; u suprotnom se ovaj teritorij oslabljuje za 3
  • void defend() – povećava razinu obrane za 5 i zatvara bedeme (postavlja zaštitu na true)

Konkretne klase imaju jedan konstruktor, a primjer njihova pozivanja prikazan je u isječku dane metode main u klasi Main:

Territory england = new Territory("England", 100);  // name, defenseLevel
Territory france  = new Territory("France", 80);
Soldier s         = new Soldier("Infantry", 40, 0); // name, defenseLevel, fieldsMoved
Tank tank         = new Tank("Heavy Tank", 80, 0);  // name, defenseLevel, fieldsMoved

NAPOMENA: Sve klase i sučelja trebaju imati vidljivost postavljenu na public i nalaziti se u paketu hr.fer.oop.
