Vaš je zadatak modelirati program koji predstavlja servis za praćenje pogledanih filmova, potrebno je nadopuniti programski kod klasa MovieRecord i MovieLambdas. Klasa MovieRecord sadrži zapise o pogledanim filmovima, a sastoji se od 8 atributa minimalne vidljivosti:

  • String title - predstavlja naziv filma,
  • String director - predstavlja redatelja filma,
  • List<String> actors - predstavlja listu glavnih glumaca filma,
  • String genre - predstavlja žanr filma,
  • int runtimeMinutes - predstavlja trajanje filma izraženo u minutama,
  • double rating - predstavlja korisničku ocjenu filma,
  • int rewatchCount - predstavlja broj ponovnih gledanja filma i
  • LocalDate watchDate - predstavlja datum gledanja filma.

NAPOMENE: Sve statičke metode potrebno je implementirati kao lambda izraze koristeći Java Stream API (tj. kolekcijske tokove). Pri implementaciji nije potrebno hvatati niti obrađivati iznimke. Klasa MovieLambdas treba se nalaziti u paketu hr.fer.oop, a ona i sve statičke metode trebaju imati maksimalnu vidljivost.

Statička metoda filterAndSortMovies

Ulazni argumenti su: 1) kolekcija filmskih zapisa, 2) predikat filmskog zapisa i 3) komparator filmskog zapisa. Potrebno je vratiti izlaznu kolekciju filmskih zapisa koja predstavlja filtriranu i sortiranu ulaznu kolekciju filmskih zapisa. Filtriranje ulazne kolekcije potrebno je napraviti na način da u izlaznoj kolekciji preostanu samo filmski zapisi koji zadovoljavaju predani predikat. Sortiranje izlazne kolekcije potrebno je ostvariti predanim komparatorom te vratiti prvih 5 filmskih zapisa.

Statička metoda moviesThisYear

Ova metoda prima tok filmskih zapisa i vraća Stream<MovieRecord> koji sadrži samo filmove koji su pogledani u trenutnoj kalendarskoj godini. Za određivanje trenutne godine koristite LocalDate.now().

Statička metoda directorMovieTitles

Ova metoda prima kolekciju filmskih zapisa i vraća tok nizova znakova u formatu "Director: Movie Title" za svaki film u kolekciji. Svaki redatelj se pojavljuje onoliko puta koliko ima njegovih filmova u kolekciji.

Statička metoda topThreeDirectors

Ova metoda prima kolekciju filmskih zapisa i vraća tok od 3 redatelja s najvećom prosječnom ocjenom filmova u padajućem poretku.
