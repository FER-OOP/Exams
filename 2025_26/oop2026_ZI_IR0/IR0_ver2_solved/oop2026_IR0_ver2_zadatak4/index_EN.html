Static method moviesThisYear

This method takes a stream of movie records and returns a Stream<MovieRecord> containing only movies that were watched in the current calendar year. Use LocalDate.now() to determine the current year.

Static method directorMovieTitles

This method takes a collection of movie records and returns a stream of strings in the format "Director: Movie Title" for each movie in the collection. Each director appears as many times as they have movies in the collection.

Static method topThreeDirectors

This method takes a collection of movie records and returns a stream of the names of the top 3 directors with the highest average movie rating in descending order.
