The directory tree contains numerous log files (.log) that record the activity of some system. You need to traverse the directory tree and analyze all .log files to determine which ones contain recorded errors.

Each line of a log file begins with a log level (INFO, WARN, or ERROR), and a line that begins with ERROR represents a recorded error. For each log file (i.e., a file with the exact .log extension), you need to count how many lines begin with ERROR. A file is considered critical if its total number of errors exceeds 5.

To traverse the directory tree, you need to write a class LogVisitor that (directly or indirectly) implements the FileVisitor interface.

The LogVisitor class must implement the following public methods:

  • int getTotalErrors() — returns the total number of error lines (ERROR) across all examined log files (see the last IMPORTANT warning),

  • String getWorstFile() — returns the full path to the file with the highest number of errors (see the output and note at the end),

  • Collection<String> getCriticalFiles() — returns the alphabetically sorted names of the files considered critical.

You also need to complete the Main class, which is partially written. You need to implement the static method

void callVisitor(Path startDir, FileVisitor<Path> visitor)

in which the visitor traverses the directory tree and computes the required values. If an exception occurs while invoking the visitor, the printStackTrace() method of the corresponding exception class should be called.

The classes should be in the package hr.fer.oop.

IMPORTANT: For working with files, you must use the java.nio.file.Path class!

IMPORTANT: Take into account only files with the .log extension. All other files must be ignored.

IMPORTANT: A line counts as an error only if it begins with ERROR.

IMPORTANT: You may assume that no two files will have the same (highest) number of errors.

IMPORTANT: You may assume that all files are correctly formatted and that no errors or exceptions will occur while traversing the directory tree.

Example .log file:

WARN	Switching to backup database
ERROR	Backup database unavailable
INFO	Activating offline mode

Example run:

Example of subdirectories inside src/main/resources/:
-- logs_10_3
------ connection.log		// 7 ERRORS
-- logs_11_3
------ A_Server
---------- access.log		// 6 ERRORS
---------- permissions.log	// 0 ERRORS
------ queries.log		// 5 ERRORS

	Path startDir = Path.of("src/main/resources/");
	LogVisitor visitor = new LogVisitor();
	callVisitor(startDir, visitor);
	System.out.println("Total errors: " + visitor.getTotalErrors());
	System.out.println("Worst file: " + visitor.getWorstFile());
	System.out.println("Critical files: ");
	for (String path : visitor.getCriticalFiles()) {
		System.out.println(path);
	}

Expected output:

Total errors: 18
Worst file: src/main/resources/logs_10_3/connection.log (or src\main\resources\logs_10_3\connection.log) 
Critical files:
access.log
connection.log

NOTE: The path separator depends on the OS — on Windows, Worst file will be printed as src\main\resources\logs_10_3\connection.log. (The path output in your solution must be independent of the operating system, i.e. it must work correctly on any platform.)
