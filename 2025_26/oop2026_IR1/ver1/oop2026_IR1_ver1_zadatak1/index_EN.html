Your task is to implement part of a stadium access-control system for the Football World Cup 2026. The system works with regular fans, press members, and staff members who may enter different areas of the stadium.

The classes Main, StadiumPerson, and StadiumGate are provided. Read them to understand how the remaining types are used. The provided classes must not be modified.

Implement the following types in the package hr.fer.oop:

  • StadiumArea
  • AccreditedPerson
  • RegularFan
  • PressMember
  • StaffMember

For AccreditedPerson, choose the appropriate kind of Java type based on how it is used in the provided program and in the description below.

Note: All types, constructors, and listed methods must have public visibility. All attributes that you implement must have private visibility.

Recommendation: Fields whose values do not change after construction are recommended to be declared using the final keyword. The use of final will not be graded separately.

StadiumArea

The type StadiumArea represents stadium areas controlled by gates. Its possible values are:

STANDS
PRESS_AREA
STAFF_AREA

StadiumArea contains only these values and has no additional fields, constructors, or methods.

Provided class StadiumPerson

The class StadiumPerson represents a person at the stadium. Every person has a name (name) and an identification code (idCode) of type String.

The class already contains:

  • the constructor StadiumPerson(String name, String idCode)
  • the method String getName()
  • the method String getIdCode()
  • the abstract method boolean canEnter(StadiumArea area)
  • an implementation of the standard toString() method

The toString() method returns the name and identification code in the following form:

Ana (F101)

Each concrete subclass must implement canEnter to determine whether the person may enter the given stadium area.

AccreditedPerson

Objects of type AccreditedPerson represent people with official accreditation. The type must contain the following two methods:

  • Set<StadiumArea> getAccreditedAreas() — returns the set of stadium areas for which the person has accreditation
  • boolean hasAccreditationFor(StadiumArea area) — returns true if the person has accreditation for the given stadium area and false otherwise

Import java.util.Set to use the collection type.

PressMember and StaffMember must be usable as AccreditedPerson objects. RegularFan does not have accreditation.

RegularFan

The class RegularFan represents a regular fan. It extends StadiumPerson.

The class has the following field:

private String seatNumber;

Implement:

  • the constructor RegularFan(String name, String idCode, String seatNumber)
  • the method String getSeatNumber()
  • the method boolean canEnter(StadiumArea area)

A regular fan may enter only STANDS.

PressMember

The class PressMember represents an accredited press member. It extends StadiumPerson and must be usable as an AccreditedPerson.

The class has the following field:

private Set<StadiumArea> accreditedAreas;

Implement:

  • the constructor PressMember(String name, String idCode, Set<StadiumArea> accreditedAreas)
  • the method Set<StadiumArea> getAccreditedAreas()
  • the method boolean hasAccreditationFor(StadiumArea area)
  • the method boolean canEnter(StadiumArea area)

The constructor must ensure that later modifications to the supplied set do not affect the object's internal state. You may assume that the supplied set is not null.

getAccreditedAreas() must return a set that cannot be used to modify the object's internal state. This may be achieved by returning a copy or an unmodifiable set.

hasAccreditationFor(area) returns true when the given area is contained in accreditedAreas.

A press member may enter:

  • STANDS
  • every area for which the press member has accreditation

StaffMember

The class StaffMember represents an accredited staff member. It extends StadiumPerson and must be usable as an AccreditedPerson.

The class has the following fields:

private StadiumArea assignedArea;
private boolean onDuty;

assignedArea represents the stadium area to which the staff member is assigned, while onDuty indicates whether the staff member is currently working.

Implement:

  • the constructor StaffMember(String name, String idCode, StadiumArea assignedArea, boolean onDuty)
  • the method StadiumArea getAssignedArea()
  • the method boolean isOnDuty()
  • the method void setOnDuty(boolean onDuty)
  • the method Set<StadiumArea> getAccreditedAreas()
  • the method boolean hasAccreditationFor(StadiumArea area)
  • the method boolean canEnter(StadiumArea area)

getAccreditedAreas() returns a set containing only assignedArea.

hasAccreditationFor(area) returns true only when the given area is equal to assignedArea.

A staff member may enter only while on duty (onDuty == true). While on duty, the staff member may enter:

  • STANDS
  • the assigned stadium area

When the staff member is not on duty, canEnter must return false for every area.

Provided class StadiumGate

The class StadiumGate represents a stadium gate. Each gate has a name and controls one stadium area.

The method:

String scanPerson(StadiumPerson person)

calls canEnter on the supplied person and returns a message indicating whether entry is allowed or denied.

Provided class Main

Each concrete class has one constructor. Examples of their use are shown in the provided Main class. The comment below each output statement shows the expected result of that statement.

package hr.fer.oop;

import java.util.Set;

public class Main {
    public static void main(String[] args) {
        StadiumPerson ana = new RegularFan("Ana", "F101", "A12");

        StadiumPerson clara = new PressMember(
                "Clara",
                "P303",
                Set.of(StadiumArea.PRESS_AREA, StadiumArea.STAFF_AREA)
        );

        StadiumPerson diego = new StaffMember(
                "Diego",
                "S404",
                StadiumArea.STAFF_AREA,
                true
        );

        StadiumGate standsGate =
                new StadiumGate("STANDS-1", StadiumArea.STANDS);
        StadiumGate pressGate =
                new StadiumGate("PRESS-1", StadiumArea.PRESS_AREA);
        StadiumGate staffGate =
                new StadiumGate("STAFF-1", StadiumArea.STAFF_AREA);

        System.out.println(ana);
        // Ana (F101)
        System.out.println(standsGate.scanPerson(ana));
        // Gate STANDS-1: Ana allowed to enter STANDS
        System.out.println(pressGate.scanPerson(ana));
        // Gate PRESS-1: Ana denied access to PRESS_AREA

        System.out.println();

        System.out.println(clara);
        // Clara (P303)
        AccreditedPerson pressAccreditation = (AccreditedPerson) clara;
        System.out.println(pressAccreditation.getAccreditedAreas().size());
        // 2
        System.out.println(
                pressAccreditation.hasAccreditationFor(StadiumArea.PRESS_AREA));
        // true
        System.out.println(pressGate.scanPerson(clara));
        // Gate PRESS-1: Clara allowed to enter PRESS_AREA
        System.out.println(staffGate.scanPerson(clara));
        // Gate STAFF-1: Clara allowed to enter STAFF_AREA

        System.out.println();

        StaffMember staff = (StaffMember) diego;
        AccreditedPerson staffAccreditation = staff;

        System.out.println(diego);
        // Diego (S404)
        System.out.println(staffAccreditation.getAccreditedAreas().size());
        // 1
        System.out.println(
                staffAccreditation.hasAccreditationFor(StadiumArea.STAFF_AREA));
        // true
        System.out.println(staffGate.scanPerson(diego));
        // Gate STAFF-1: Diego allowed to enter STAFF_AREA

        staff.setOnDuty(false);

        System.out.println(staff.isOnDuty());
        // false
        System.out.println(staffGate.scanPerson(diego));
        // Gate STAFF-1: Diego denied access to STAFF_AREA
        System.out.println(standsGate.scanPerson(diego));
        // Gate STANDS-1: Diego denied access to STANDS
    }
}
