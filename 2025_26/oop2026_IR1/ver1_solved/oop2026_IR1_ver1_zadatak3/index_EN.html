Files containing FIFA World Cup match data are located in a directory tree. It is necessary to traverse the given directory and all of its subdirectories and process all .txt files contained within them.

Each file contains match data. The first line of each file contains column names and should be skipped. Every subsequent line represents a single match.

The data in each line is separated by tab characters and has the following format:

Group	Date	Home	Score	Away	Stadium
A	2026-06-11	Mexico	2-0	South Africa	Estadio Azteca

A provided class WorldCupGameInfo is used to store match information.

The class contains the following public attributes:

String group
String date
String homeTeam
String awayTeam
int homeGoals
int awayGoals
String stadium

and the following static method:

static WorldCupGameInfo createFromString(String line)

which creates a WorldCupGameInfo object from a single line of the file.

You need to implement the class WorldCupFileVisitor, which extends SimpleFileVisitor<Path>.

The class should traverse all .txt files, regardless of their extension, and identify all national teams that did not suffer a single defeat in any of the processed matches.

The class must implement the following method:

Set<String> getUnbeatenTeams()

The method returns a set of national teams that have not lost a single match.

The set must be sorted:

by the length of the team name in ascending order, if two team names have the same length, by the natural ordering of strings in alphabetical order.

It is also necessary to complete the MainClass class. You need to implement the static method

static void callVisitor(Path datafolder, FileVisitor<Path> visitor)

which traverses the directory tree using the provided visitor.

All classes should be placed in the package hr.fer.oop.

IMPORTANT: You must use the java.nio.file.Path when working with files.

You may assume that all .txt files are correctly formatted.

A	2026-06-11	Mexico	2-0	South Africa	Estadio Azteca
A	2026-06-11	South Korea	2-1	Czechia	Estadio Guadalajara
A	2026-06-18	Mexico	1-1	South Korea	Estadio Azteca

A	2026-06-24	Czechia	0-1	Mexico	MetLife Stadium
A	2026-06-24	South Africa	0-2	South Korea	Levi's Stadium

The unbeaten teams are:

Mexico
