U stablu direktorija nalaze se datoteke koje sadrže podatke o utakmicama Svjetskog prvenstva. Potrebno je obići zadani direktorij i sve njegove poddirektorije te obraditi sve .txt datoteke koje se u njima nalaze.

Svaka datoteka sadrži podatke o utakmicama. Prvi redak datoteke sadrži nazive stupaca i potrebno ga je preskočiti. Svaki sljedeći redak predstavlja jednu utakmicu.

Podaci u retku odvojeni su tabulatorom i imaju oblik:

Group	Date	Home	Score	Away	Stadium
A	2026-06-11	Mexico	2-0	South Africa	Estadio Azteca

Za spremanje podataka o utakmici koristi se gotova klasa WorldCupGameInfo.

Klasa ima javne atribute:

String group
String date
String homeTeam
String awayTeam
int homeGoals
int awayGoals
String stadium

i statičku metodu:

static WorldCupGameInfo createFromString(String line)

koja iz jednog retka datoteke stvara objekt tipa WorldCupGameInfo.

Potrebno je napisati klasu WorldCupFileVisitor koja nasljeđuje SimpleFileVisitor<Path>.

Klasa treba obići sve .txt datoteke te pronaći sve reprezentacije koje tijekom pročitanih utakmica nisu doživjele nijedan poraz.

Klasa mora implementirati metodu:

Set<String> getUnbeatenTeams()

Metoda vraća skup reprezentacija koje nisu izgubile nijednu utakmicu.

Skup mora biti sortiran:

  1. po duljini naziva reprezentacije uzlazno
  2. ako je duljina jednaka, prirodnim poretkom stringova abecednim redom.

Potrebno je dopuniti i klasu MainClass metodom:

static void callVisitor(Path datafolder, FileVisitor<Path> visitor)

u kojoj se pomoću visitora obilazi stablo direktorija.

Sve klase trebaju biti u paketu hr.fer.oop.
