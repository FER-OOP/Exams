Potrebno je implementirati pojednostavljeni sustav za upravljanje igraonicom s arkadnim automatima. Automati se ne pohranjuju izravno u igraonicu, već su raspoređeni u prostorije.

Klase GameRoom i Arcade djelomično su implementirane i potrebno ih je dovršiti. Klasa DuplicateException nije implementirana i potrebno ju je napisati prema priloženom dijagramu klasa. Klase ArcadeMachine, RacingMachine, RhythmMachine i Main priložene su uz zadatak i ne mijenjate ih.

Sve klase su public i nalaze se u paketu hr.fer.oop.

VAŽNO: U djelomično implementiranim klasama dopušteno je i prema potrebi potrebno mijenjati deklaracije klasa i metoda, uključujući generičke parametre i throws deklaracije.

Dijagram klasa

ArcadeMachine je apstraktna klasa koja opisuje zajednička svojstva svih arkadnih automata. Konkretne vrste automata predstavljene su klasama RacingMachine i RhythmMachine.

Klasa GameRoom predstavlja prostoriju koja može sadržavati automate samo jedne konkretne vrste. Klasa mora biti parametrizirana tako da je dopušteno koristiti samo tipove izvedene iz klase ArcadeMachine.

Metoda addMachine dodaje automat u prostoriju. Unutar iste prostorije ne smiju postojati dva automata s jednakom oznakom code. Ako automat s jednakom oznakom već postoji, metoda baca provjeravanu iznimku DuplicateException.

Metoda getMachines vraća nepromjenjivu listu automata koji se trenutačno nalaze u prostoriji. Vraćena lista ne smije omogućiti promjenu interne liste prostorije.

Metoda findMachine vraća automat sa zadanom oznakom. Ako takav automat ne postoji, metoda vraća null.

Metoda getMachinesRequiringAtMost vraća novu listu automata koji zahtijevaju najviše zadani broj žetona. Redoslijed automata u vraćenoj listi mora odgovarati redoslijedu njihova dodavanja u prostoriju.

Nadjačajte metodu toString() klase GameRoom tako da vraća naziv prostorije i broj automata u formatu prikazanom u primjeru ispisa, primjerice:

Racing room (2 machine(s))

Klasa Arcade predstavlja igraonicu koja se sastoji od više prostorija, pri čemu svaka prostorija sadrži automate jedne konkretne vrste. Različite prostorije mogu sadržavati različite vrste automata.

Prostorije su spremljene u mapi rooms. Ključ mape je naziv prostorije, a vrijednost je odgovarajući objekt tipa GameRoom. Potpuna generička deklaracija atributa rooms priložena je u početnom kodu.

Metoda addRoom dodaje prostoriju u igraonicu. Ako prostorija s jednakim nazivom već postoji, metoda baca provjeravanu iznimku DuplicateException.

Metoda findRoom vraća prostoriju sa zadanim nazivom. Ako takva prostorija ne postoji, metoda vraća null.

Metoda getTotalMachineCount vraća ukupan broj automata u svim prostorijama igraonice.

Metoda findMachine pretražuje sve prostorije i vraća automat sa zadanom oznakom. Ako takav automat ne postoji ni u jednoj prostoriji, metoda vraća null.

VAŽNO: Tekst poruke iznimke nije propisan i neće se bodovati. Važno je baciti odgovarajuću vrstu iznimke u propisanoj situaciji.

Možete pretpostaviti da argumenti predani konstruktorima i metodama neće biti null. Također možete pretpostaviti da automati smješteni u različitim prostorijama neće imati jednake oznake.

Primjer pokretanja

package hr.fer.oop;

public class Main {
    public static void main(String[] args) {
        GameRoom<RacingMachine> racingRoom =
                new GameRoom<>("Racing room");
        GameRoom<RhythmMachine> rhythmRoom =
                new GameRoom<>("Rhythm room");

        try {
            racingRoom.addMachine(
                    new RacingMachine("R-001", "Turbo Drift", 3, 220));
            racingRoom.addMachine(
                    new RacingMachine("R-002", "Night Racers", 4, 260));
            rhythmRoom.addMachine(
                    new RhythmMachine("M-001", "Beat Master", 2, 40));
            rhythmRoom.addMachine(
                    new RhythmMachine("M-002", "Dance Floor", 1, 25));
        } catch (DuplicateException e) {
            System.out.println("A duplicate machine was detected.");
        }

        Arcade arcade = new Arcade();

        try {
            arcade.addRoom(racingRoom);
            arcade.addRoom(rhythmRoom);
        } catch (DuplicateException e) {
            System.out.println("A duplicate room was detected.");
        }

        System.out.println(racingRoom);
        System.out.println(rhythmRoom);
        System.out.println("Total machines: "
                + arcade.getTotalMachineCount());

        System.out.println("\nRacing machines:");
        for (RacingMachine machine : racingRoom.getMachines()) {
            System.out.println(machine);
        }

        System.out.println(
                "\nRhythm machines requiring at most 2 tokens:");
        for (RhythmMachine machine
                : rhythmRoom.getMachinesRequiringAtMost(2)) {
            System.out.println(machine);
        }

        System.out.println("\nFound machine: "
                + arcade.findMachine("M-001"));
        System.out.println("Missing machine: "
                + arcade.findMachine("X-404"));
        System.out.println("Missing room: "
                + arcade.findRoom("Unknown room"));

        try {
            racingRoom.addMachine(
                    new RacingMachine("R-001", "Speed Challenge", 2, 200));
        } catch (DuplicateException e) {
            System.out.println("Duplicate machine detected.");
        }

        try {
            arcade.addRoom(
                    new GameRoom<RacingMachine>("Racing room"));
        } catch (DuplicateException e) {
            System.out.println("Duplicate room detected.");
        }

        try {
            racingRoom.getMachines().add(
                    new RacingMachine("R-003", "Road King", 2, 180));
        } catch (UnsupportedOperationException e) {
            System.out.println(
                    "The returned machine list is unmodifiable.");
        }
    }
}
