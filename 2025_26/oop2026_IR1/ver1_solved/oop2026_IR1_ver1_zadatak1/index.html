Vaš je zadatak implementirati dio sustava kontrole pristupa stadionu tijekom Svjetskog nogometnog prvenstva 2026. Sustav radi s običnim navijačima, predstavnicima medija i članovima osoblja koji mogu ulaziti u različite dijelove stadiona.

U zadatku su dane klase Main, StadiumPerson i StadiumGate. Potrebno ih je pročitati kako bi se vidjelo na koji se način koriste ostali tipovi. Dane klase nije dozvoljeno mijenjati.

Potrebno je implementirati sljedeće tipove u paketu hr.fer.oop:

  • StadiumArea
  • AccreditedPerson
  • RegularFan
  • PressMember
  • StaffMember

Za tip AccreditedPerson potrebno je odabrati odgovarajuću vrstu tipa na temelju načina na koji se koristi u danom programu i opisu u nastavku.

Napomena: Svi tipovi, konstruktori i navedene metode moraju imati vidljivost public. Svi atributi koje implementirate moraju imati vidljivost private.

Preporuka: Atribute čija se vrijednost nakon konstrukcije ne mijenja preporučuje se označiti ključnom riječi final. Korištenje ključne riječi final neće se posebno bodovati.

StadiumArea

Tip StadiumArea predstavlja dijelove stadiona koje kontroliraju ulazi. Moguće vrijednosti su:

STANDS
PRESS_AREA
STAFF_AREA

Tip StadiumArea sadrži samo navedene vrijednosti i nema dodatna polja, konstruktore ni metode.

Zadana klasa StadiumPerson

Klasa StadiumPerson predstavlja osobu na stadionu. Svaka osoba ima ime (name) i identifikacijsku oznaku (idCode) tipa String.

Klasa već sadrži:

  • konstruktor StadiumPerson(String name, String idCode)
  • metodu String getName()
  • metodu String getIdCode()
  • apstraktnu metodu boolean canEnter(StadiumArea area)
  • implementaciju standardne metode toString()

Metoda toString() vraća ime i identifikacijsku oznaku u obliku:

Ana (F101)

Svaka konkretna podklasa mora implementirati metodu canEnter, kojom određuje smije li osoba ući u zadani dio stadiona.

AccreditedPerson

Objekti tipa AccreditedPerson predstavljaju osobe koje imaju službenu akreditaciju. Tip mora sadržavati sljedeće dvije metode:

  • Set<StadiumArea> getAccreditedAreas() — vraća skup dijelova stadiona za koje osoba ima akreditaciju
  • boolean hasAccreditationFor(StadiumArea area) — vraća true ako osoba ima akreditaciju za zadani dio stadiona, inače vraća false

Za korištenje skupa potrebno je uvesti tip java.util.Set.

PressMember i StaffMember moraju biti objekti tipa AccreditedPerson. RegularFan nema akreditaciju.

RegularFan

Klasa RegularFan predstavlja običnog navijača. Ona nasljeđuje klasu StadiumPerson.

Klasa ima atribut:

private String seatNumber;

Potrebno je implementirati:

  • konstruktor RegularFan(String name, String idCode, String seatNumber)
  • metodu String getSeatNumber()
  • metodu boolean canEnter(StadiumArea area)

Obični navijač smije ući samo u područje STANDS.

PressMember

Klasa PressMember predstavlja akreditiranog predstavnika medija. Ona nasljeđuje klasu StadiumPerson i mora se moći koristiti kao AccreditedPerson.

Klasa ima atribut:

private Set<StadiumArea> accreditedAreas;

Potrebno je implementirati:

  • konstruktor PressMember(String name, String idCode, Set<StadiumArea> accreditedAreas)
  • metodu Set<StadiumArea> getAccreditedAreas()
  • metodu boolean hasAccreditationFor(StadiumArea area)
  • metodu boolean canEnter(StadiumArea area)

Konstruktor mora osigurati da naknadne promjene nad predanim skupom ne utječu na interno stanje objekta. Može se pretpostaviti da predani skup nije null.

Metoda getAccreditedAreas() mora vratiti skup preko kojeg nije moguće promijeniti interno stanje objekta. To se može postići vraćanjem kopije skupa ili vraćanjem nepromjenjivog skupa.

Metoda hasAccreditationFor(area) vraća true ako se zadano područje nalazi u skupu accreditedAreas.

Predstavnik medija smije ući:

  • u područje STANDS
  • u svako područje za koje ima akreditaciju

StaffMember

Klasa StaffMember predstavlja akreditiranog člana osoblja. Ona nasljeđuje klasu StadiumPerson i mora se moći koristiti kao AccreditedPerson.

Klasa ima atribute:

private StadiumArea assignedArea;
private boolean onDuty;

Atribut assignedArea predstavlja područje stadiona kojem je član osoblja dodijeljen, a onDuty označava je li trenutačno na dužnosti.

Potrebno je implementirati:

  • konstruktor StaffMember(String name, String idCode, StadiumArea assignedArea, boolean onDuty)
  • metodu StadiumArea getAssignedArea()
  • metodu boolean isOnDuty()
  • metodu void setOnDuty(boolean onDuty)
  • metodu Set<StadiumArea> getAccreditedAreas()
  • metodu boolean hasAccreditationFor(StadiumArea area)
  • metodu boolean canEnter(StadiumArea area)

Metoda getAccreditedAreas() vraća skup koji sadrži samo vrijednost assignedArea.

Metoda hasAccreditationFor(area) vraća true samo ako je zadano područje jednako području assignedArea.

Član osoblja smije ući samo ako je na dužnosti (onDuty == true). Kada je na dužnosti, smije ući:

  • u područje STANDS
  • u područje kojem je dodijeljen

Ako nije na dužnosti, metoda canEnter mora vratiti false za sva područja.

Zadana klasa StadiumGate

Klasa StadiumGate predstavlja ulaz na stadion. Svaki ulaz ima naziv i kontrolira jedno područje stadiona.

Metoda:

String scanPerson(StadiumPerson person)

poziva metodu canEnter nad predanom osobom i vraća poruku o dopuštenom ili odbijenom ulasku.

Zadana klasa Main

Konkretne klase imaju po jedan konstruktor. Primjeri njihove uporabe prikazani su u zadanoj klasi Main. Komentar ispod svakog ispisa prikazuje očekivani rezultat tog ispisa.

package hr.fer.oop;

import java.util.Set;

public class Main {
    public static void main(String[] args) {
        StadiumPerson ana = new RegularFan("Ana", "F101", "A12");

        StadiumPerson clara = new PressMember(
                "Clara",
                "P303",
                Set.of(StadiumArea.PRESS_AREA, StadiumArea.STAFF_AREA)
        );

        StadiumPerson diego = new StaffMember(
                "Diego",
                "S404",
                StadiumArea.STAFF_AREA,
                true
        );

        StadiumGate standsGate =
                new StadiumGate("STANDS-1", StadiumArea.STANDS);
        StadiumGate pressGate =
                new StadiumGate("PRESS-1", StadiumArea.PRESS_AREA);
        StadiumGate staffGate =
                new StadiumGate("STAFF-1", StadiumArea.STAFF_AREA);

        System.out.println(ana);
        // Ana (F101)
        System.out.println(standsGate.scanPerson(ana));
        // Gate STANDS-1: Ana allowed to enter STANDS
        System.out.println(pressGate.scanPerson(ana));
        // Gate PRESS-1: Ana denied access to PRESS_AREA

        System.out.println();

        System.out.println(clara);
        // Clara (P303)
        AccreditedPerson pressAccreditation = (AccreditedPerson) clara;
        System.out.println(pressAccreditation.getAccreditedAreas().size());
        // 2
        System.out.println(
                pressAccreditation.hasAccreditationFor(StadiumArea.PRESS_AREA));
        // true
        System.out.println(pressGate.scanPerson(clara));
        // Gate PRESS-1: Clara allowed to enter PRESS_AREA
        System.out.println(staffGate.scanPerson(clara));
        // Gate STAFF-1: Clara allowed to enter STAFF_AREA

        System.out.println();

        StaffMember staff = (StaffMember) diego;
        AccreditedPerson staffAccreditation = staff;

        System.out.println(diego);
        // Diego (S404)
        System.out.println(staffAccreditation.getAccreditedAreas().size());
        // 1
        System.out.println(
                staffAccreditation.hasAccreditationFor(StadiumArea.STAFF_AREA));
        // true
        System.out.println(staffGate.scanPerson(diego));
        // Gate STAFF-1: Diego allowed to enter STAFF_AREA

        staff.setOnDuty(false);

        System.out.println(staff.isOnDuty());
        // false
        System.out.println(staffGate.scanPerson(diego));
        // Gate STAFF-1: Diego denied access to STAFF_AREA
        System.out.println(standsGate.scanPerson(diego));
        // Gate STANDS-1: Diego denied access to STANDS
    }
}
