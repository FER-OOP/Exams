Grad Zagreb raspolaže sustavom javnih bicikala Bajs. U ovom zadatku analiziraju se podaci o vožnjama.

Pojedinačna vožnja predstavljena je objektom klase Ride. Klasa sadrži podatke o nazivu početne stanice, nazivu završne stanice i trajanju vožnje u minutama.

Potrebno je dovršiti statičke metode u klasi Task koristeći Stream API.

1. Filtriranje vožnji prema odredištu

Dovršite metodu

public static List<Ride> getRidesToStation(Stream<Ride> rides, String station)

koja prima tok vožnji rides i naziv završne stanice station. Metoda mora vratiti listu svih vožnji iz predanog toka čija je završna stanica jednaka zadanoj stanici station. Vožnje u rezultatu potrebno je poredati uzlazno prema trajanju vožnje.

Ako nijedna vožnja ne zadovoljava uvjet, metoda treba vratiti praznu listu.

2. Određivanje frekventnih stanica

Dovršite metodu

public static Stream<String> frequentStations(Stream<Ride> rides, int minRides, int minDuration)

koja prima tok vožnji rides. Metoda mora vratiti tok naziva početnih stanica stanica s kojih je započelo barem minRides vožnji čije je trajanje barem minDuration minuta.

Primjerice, za minRides jednak 2 i minDuration jednak 10, metoda vraća nazive stanica s kojih su započele barem dvije vožnje u trajanju od najmanje 10 minuta.

Ako su zadani sljedeći podaci:

List<Ride> rides = List.of(
   new Ride("MLADOST", "TRŽNICA JARUN", 12), 
   new Ride("MLADOST", "CENTAR", 15), 
   new Ride("MLADOST", "AUTOBUSNI KOLODVOR", 5),
   
   new Ride("TRŽNICA JARUN", "MLADOST", 20),
   new Ride("TRŽNICA JARUN", "CENTAR", 25),
    
   new Ride("AUTOBUSNI KOLODVOR", "CENTAR", 7),
   new Ride("AUTOBUSNI KOLODVOR", "MLADOST", 8)
);

poziv

frequentStations(rides.stream(), 2, 10)

vraća tok koji, neovisno o redoslijedu, sadrži:

MLADOST
TRŽNICA JARUN

Stanica MLADOST zadovoljava uvjet jer dvije od njezine tri vožnje traju barem 10 minuta. Stanica TRŽNICA JARUN također zadovoljava uvjet jer obje vožnje traju barem 10 minuta. Stanica AUTOBUSNI KOLODVOR ne zadovoljava uvjet.

Rezultat mora sadržavati navedene elemente, ali njihov redoslijed nije određen.

3. Tri najčešće rute

Dovršite metodu

public static Stream<String> getTop3Routes(Stream<Ride> rides)

koja određuje najčešće korištene rute. Ruta je određena početnom i završnom stanicom, pri čemu je smjer vožnje važan. Primjerice, ruta

MLADOST -> TRŽNICA JARUN

i ruta

TRŽNICA JARUN -> MLADOST

smatraju se različitim rutama.

Tekstualni prikaz rute sastoji se od naziva početne stanice, znaka " -> " i naziva završne stanice. Metoda treba vratiti tok koji sadrži najviše tri najčešće korištene rute. Rute je potrebno poredati prema sljedećim kriterijima:

  1. silazno prema broju vožnji na pojedinoj ruti,

  2. ako dvije ili više ruta imaju jednak broj vožnji, abecedno prema tekstualnom prikazu rute

Ako postoje manje od tri različite rute, vraćaju se sve postojeće rute. Ako je ulazni tok prazan, vraća se prazan tok.

Primjer ulaznih podataka:

List<Ride> rides = List.of(
    new Ride("MLADOST", "TRŽNICA JARUN", 12),
    new Ride("MLADOST", "TRŽNICA JARUN", 14),
    new Ride("MLADOST", "TRŽNICA JARUN", 11),
    new Ride("AUTOBUSNI KOLODVOR", "TRG KRALJA TOMISLAVA", 9),
    new Ride("AUTOBUSNI KOLODVOR", "TRG KRALJA TOMISLAVA", 10),
    new Ride("NACIONALNA I SVEUČILIŠNA KNJIŽNICA", "AUTOBUSNI KOLODVOR", 8),
    new Ride("NACIONALNA I SVEUČILIŠNA KNJIŽNICA", "AUTOBUSNI KOLODVOR", 7),
    new Ride("TRŽNICA JARUN", "MLADOST", 13),
    new Ride("TRG KRALJA TOMISLAVA", "S.D. STJEPAN RADIĆ", 24)
);

Za navedene podatke poziv

Task.getTop3Routes(rides.stream())

vraća tok koji sadrži sljedeće elemente navedenim redoslijedom:

MLADOST -> TRŽNICA JARUN 
AUTOBUSNI KOLODVOR -> TRG KRALJA TOMISLAVA 
NACIONALNA I SVEUČILIŠNA KNJIŽNICA -> AUTOBUSNI KOLODVOR

NAPOMENA: Sve metode potrebno je implementirati korištenjem Stream API-ja. Nije dozvoljeno mijenjati potpise zadanih metoda ni klasu Ride.
