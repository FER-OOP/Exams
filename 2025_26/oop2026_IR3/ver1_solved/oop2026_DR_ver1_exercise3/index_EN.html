In this exercise you need to finish the reading of ASCII pictures out of binary files.

The classes Span and Picture are given and you must not change them. What you write is the reader and the exceptions it throws.

IMPORTANT

The exception classes must hold exactly the attributes shown in the diagram and no others, and each is built by the constructor shown and no other. Any further attribute in an exception class costs 20% of the whole exercise.

The file format

Every file holds one picture.

It begins with a heading of 7 bytes:

sizefieldmeans
2 byteswidthhow many columns the picture has
2 bytesheighthow many rows the picture has
1 byteblankthe character that fills the "empty" cells
2 bytescounthow many spans come after the heading

Then come exactly count spans, one after another. Every span is seven bytes, in this order:

sizefieldmeans
2 bytesrowthe row the span is in
2 bytescolumnthe column it starts at
2 byteslengthhow many characters it draws
1 bytecharacterthe character it draws

Two-byte numbers are written with the higher byte first.

A span always goes to the right, starting at its own column and staying in its own row.

The exceptions

All the exceptions are checked. PictureException cannot be instantiated directly. It carries the path to the file (Path) the trouble was in.

  • TruncatedFileException — the file stops before it has given everything it promised. It carries (entry) the number of the span it stopped inside (counted from 1), or 0 for the heading;
  • ExtraDataException — there is more in the file than the heading promised, that is, something is left after the last span;
  • OutsidePictureException — the span (Span) numbered entry falls outside the picture. A span has to fit whole inside the picture, both its first and its last character. Counted from 1.
  • PictureIOException — the file or the directory could not be read at all. An IOException happened, and it is the cause (cause) of the PictureIOException.

Class PictureReader

The constant EXTENSION and the methods readShort and readChar are already given.

  • readShort is a helper that uses your implementation of readByte to read two consecutive bytes into one number.
  • readChar is a helper that uses your implementation of readByte to read one ASCII character.

You need to implement

readByte

private static int readByte(InputStream in, Path file, int entry)
    throws IOException, TruncatedFileException

Reads one byte. If the end of the file has been reached, it throws a TruncatedFileException.

read

The method reads the heading and loads exactly count spans into the Picture it returns. It also has to throw the appropriate exception when something is wrong.

To check whether a position exists in the picture you can use:

picture.holds(row, column)

readAll

Loads every .pic file lying directly in the given directory and returns their pictures.

It does not walk into subdirectories.

If the directory cannot be read, a PictureIOException is thrown. If read throws some other PictureException, it is passed on to the caller.

The file src/main/resources/fileset0/03-dot.pic is a picture 5 wide and 3 tall, blank everywhere except for a single *. All 14 of its bytes:

Usage example

// FILESET is src/main/resources/fileset0
// every .pic file lying directly in the directory, so nothing from broken/
List<Picture> pictures = PictureReader.readAll(FILESET);

System.out.println("READ: " + pictures.size());
for (Picture picture : pictures) {
  System.out.println("SIZE: " + picture.getWidth() + "x" + picture.getHeight());
  System.out.println(picture);
}

// the files in broken/ cannot be read, each one for its own reason
Path broken = FILESET.resolve("broken");
for (String name : new String[] { "extra.pic", "outside.pic", "short.pic" }) {
  try {
    PictureReader.read(broken.resolve(name));
  } catch (OutsidePictureException failure) {
    System.out.println("OUTSIDE:   " + name + " entry " + failure.getEntry()
        + " reaches row " + failure.getRow() + " column " + failure.getColumn());
  } catch (TruncatedFileException failure) {
    System.out.println("TRUNCATED: " + name + " entry " + failure.getEntry());
  } catch (PictureException failure) {
    System.out.println("REFUSED:   " + name);
  }
}
