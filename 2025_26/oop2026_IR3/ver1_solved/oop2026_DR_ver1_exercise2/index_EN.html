The City of Zagreb operates the Bajs public bicycle system. In this task, data about rides between Bajs stations are analyzed.

An individual ride is represented by an object of the Ride class. The class contains information about the name of the start station, the name of the end station, and the ride duration in minutes.

You need to complete the static methods in the Task class using the Stream API.

1. Filtering rides by destination

Complete the method

public static List<Ride> getRidesToStation(Stream<Ride> rides, String station)

which takes a stream of rides rides and the name of an end station station. The method must return a list of all rides from the given stream whose end station is equal to the specified station. The rides in the result must be sorted in ascending order by ride duration.

If no ride satisfies the condition, the method should return an empty list.

2. Determining frequent stations

Complete the method

public static Stream<String> frequentStations(Stream<Ride> rides, int minRides, int minDuration)

wwhich takes a stream of rides rides. The method must return a stream containing the names of starting stations that have at least minRides rides with a duration of at least minDuration minutes. For example, if minRides is equal to 2 and minDuration is equal to 10, the method returns the names of stations from which at least two rides with a duration of at least 10 minutes started. Given the following data:

List<Ride> rides = List.of(
   new Ride("MLADOST", "TRŽNICA JARUN", 12), 
   new Ride("MLADOST", "CENTAR", 15), 
   new Ride("MLADOST", "AUTOBUSNI KOLODVOR", 5),
   
   new Ride("TRŽNICA JARUN", "MLADOST", 20),
   new Ride("TRŽNICA JARUN", "CENTAR", 25),
    
   new Ride("AUTOBUSNI KOLODVOR", "CENTAR", 7),
   new Ride("AUTOBUSNI KOLODVOR", "MLADOST", 8)
);

the call

frequentStations(rides.stream(), 2, 10)

returns a stream containing the following elements, regardless of their order:

MLADOST
TRŽNICA JARUN

The station MLADOST satisfies the condition because two of its three rides have a duration of at least 10 minutes. The station TRŽNICA JARUN also satisfies the condition because both of its rides have a duration of at least 10 minutes. The station AUTOBUSNI KOLODVOR does not satisfy the condition.

The result must contain the specified elements, but their order is not defined.

3. Three most frequent routes

Complete the method

public static Stream<String> getTop3Routes(Stream<Ride> rides)

which determines the most frequently used routes. A route is defined by its start and end station, and the direction of the ride is significant. For example, the route

MLADOST -> TRŽNICA JARUN

and the route

TRŽNICA JARUN -> MLADOST

are considered different routes. The textual representation of a route consists of the name of the start station, the string " -> ", and the name of the end station. The method should return a stream containing at most the three most frequently used routes. The routes must be sorted according to the following criteria:

1. in descending order by the number of rides on each route,

2. if two or more routes have the same number of rides, alphabetically by their textual representation.

If there are fewer than three different routes, all existing routes are returned. If the input stream is empty, aan empty stream should be returned.

Example input data:

List<Ride> rides = List.of(
    new Ride("MLADOST", "TRŽNICA JARUN", 12),
    new Ride("MLADOST", "TRŽNICA JARUN", 14),
    new Ride("MLADOST", "TRŽNICA JARUN", 11),
    new Ride("AUTOBUSNI KOLODVOR", "TRG KRALJA TOMISLAVA", 9),
    new Ride("AUTOBUSNI KOLODVOR", "TRG KRALJA TOMISLAVA", 10),
    new Ride("NACIONALNA I SVEUČILIŠNA KNJIŽNICA", "AUTOBUSNI KOLODVOR", 8),
    new Ride("NACIONALNA I SVEUČILIŠNA KNJIŽNICA", "AUTOBUSNI KOLODVOR", 7),
    new Ride("TRŽNICA JARUN", "MLADOST", 13),
    new Ride("TRG KRALJA TOMISLAVA", "S.D. STJEPAN RADIĆ", 24)
);

For the given data, the call

Task.getTop3Routes(rides.stream())

returns:

MLADOST -> TRŽNICA JARUN 
AUTOBUSNI KOLODVOR -> TRG KRALJA TOMISLAVA 
NACIONALNA I SVEUČILIŠNA KNJIŽNICA -> AUTOBUSNI KOLODVOR

NOTE: All methods must be implemented using the Stream API. The signatures of the given methods and the Ride class must not be modified.
