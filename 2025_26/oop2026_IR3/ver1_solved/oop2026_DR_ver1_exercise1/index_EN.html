The wellness center offers various facilities that users can use. Each wellness facility (WellnessFacility) has a name (name) and a number of uses (numberOfUses), which represents how many times the facility has been used. Each time a facility is used, its number of uses is increased by 1.

The abstract class WellnessFacility, the non-abstract class RelaxationRoom, and the class Main are provided. You are required to implement the non-abstract classes HotTub, Sauna, and OutdoorPool, as well as the types WaterFacility and HeatedFacility. Based on the description below, you must determine whether the types WaterFacility and HeatedFacility should be classes or interfaces and establish the appropriate inheritance and interface implementation hierarchy. In addition to implementing the individual types of wellness facilities, you are also required to complete the WellnessUtils class, which provides operations on a collection of wellness facilities.

All non-abstract classes (OutdoorPool, HotTub, Sauna, and RelaxationRoom) have WellnessFacility as a superclass, although not necessarily as their direct superclass.

NOTE: The classes WellnessFacility and RelaxationRoom must not be modified to ensure correct grading of the solution.

Objects of types OutdoorPool and HotTub represent different types of water facilities (WaterFacility). In addition to the properties inherited from the WellnessFacility class, water facilities share common data about water temperature and capacity. The water temperature (waterTemperature) is of type double, while the capacity (capacity) is of type int. Both values are set when an object is created.

The WaterFacility type provides access to the water temperature through the double getWaterTemperature() method and to the capacity through the int getCapacity() method. To modify the water temperature, an appropriate setter must be implemented. The setter must be accessible to classes derived from the WaterFacility type, but it must not be publicly accessible.

Some wellness facilities, regardless of their type, have the additional capability of using a heating system. Such facilities are described by the HeatedFacility type. In this task, HotTub and Sauna have this capability. Facilities with heating capability may belong to different types of wellness facilities, but they all share the methods void turnHeatingOn(), void turnHeatingOff(), and boolean isHeatingOn(). When such an object is created, the heating is initially turned off. The turnHeatingOn() method turns the heating on, the turnHeatingOff() method turns it off, and the isHeatingOn() method returns whether the heating is currently on.

The behavior of individual wellness facilities is defined as follows:

  • OutdoorPool represents an outdoor pool. It is a water facility but does not have a heating system.
  • HotTub represents a jacuzzi. It is a water facility that also has a heating system. It can be used regardless of whether the heating is on. Additionally, the void heatWater(double amount) method increases the current water temperature by the value of amount, but only if the heating is on. If the heating is off, the water temperature remains unchanged. The amount parameter will always be a positive number.
  • Sauna represents a sauna. It has a heating system but is not a water facility. A call to the use() method increases the number of uses by 1 only if the heating is on. If the heating is off, the state of the object remains unchanged.
  • RelaxationRoom represents a relaxation room.

Each non-abstract class has exactly one constructor, and examples of constructor calls are shown in the provided main method in the Main class:

RelaxationRoom room = new RelaxationRoom("Quiet Room");
OutdoorPool pool = new OutdoorPool("Outdoor Pool", 24.5, 40);
HotTub hotTub = new HotTub("Jacuzzi", 34.0, 6);
Sauna sauna = new Sauna("Finnish Sauna");

All non-abstract wellness facility classes (OutdoorPool, HotTub, Sauna, and RelaxationRoom) inherit the following methods through their hierarchy:

  • String getName() – returns the name of the facility set in the constructor
  • int getNumberOfUses() – returns the number of times the facility has been used
  • void use() – uses the wellness facility according to the rules of its concrete type

Water facilities additionally provide:

  • double getWaterTemperature() – returns the water temperature
  • int getCapacity() – returns the maximum number of people who can use the facility at the same time

Facilities with heating capability additionally provide:

  • void turnHeatingOn() – turns the heating on
  • void turnHeatingOff() – turns the heating off
  • boolean isHeatingOn() – returns whether the heating is on

An object of type HotTub additionally provides:

  • void heatWater(double amount) – increases the water temperature by the specified amount if the heating is on

Class WellnessUtils

You need to to complete the WellnessUtils class, which contains the following public static method:

  • void turnOnAllHeatedFacilities(List<WellnessFacility> facilities) – turns the heating on for all facilities in the given list that have heating capability. All other facilities remain unchanged.

NOTE: All classes and interfaces must have public visibility and must be located in the hr.fer.oop package.
