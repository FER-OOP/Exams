Implement spreadsheet tables of numbers (Sheet). A rectangular part of a table is a block (Block).

Implement the yellow classes from the diagram using exactly the attributes, constructors and methods shown. The Sheet class comes started in the template, where you fill in the method bodies; the Cell and Block classes you write yourselves. Methods of your own are allowed.

Cell and Block must hold exactly the attributes shown in the UML diagram and no others. Adding any further attribute to a class costs 70% of the exercise.

Access modifiers in class diagrams:

Class Sheet

A table of rowCount rows and columnCount columns, in which every cell starts out holding 0.0. The size is set when the sheet is made and never changes. Rows and columns are counted from 0, so get(0, 0) is the top left cell, and a column is named with a single letter, so a sheet has at most MAX_COLUMNS = 26 columns. A sheet with no rows or no columns is allowed.

  • get(row, column), set(row, column, value) — read and write one cell;
  • block(firstRow, firstColumn, lastRow, lastColumn) — the rectangle between the two given cells, both included;
  • all() — the whole sheet as one block, empty if the sheet has no cells. Its implementation is given to you, but it relies on a correct implementation of block.

You may assume every value given to you is legal — sizes, rows and columns are always within bounds, so you do not have to check them.

Class Cell

One cell of a particular sheet (Sheet):

  • row, column — its position in the sheet;
  • get(), set(value) — read and write at the cell's position in the sheet, so that a later sheet.get(row, column) reads back what set wrote;
  • getLabel() — the name of the cell: columns are letters starting from A, rows are numbers starting from 1, so row 1, column 1 is called B2.

Class Block

A rectangular part of one particular sheet, which keeps no numbers of its own but reads straight from the sheet:

  • firstRow, firstColumn — the top left cell the rectangle starts at;
  • rows, columns — the number of rows and columns the rectangle spans;
  • size() — how many cells it covers in total;
  • rowMajor(), columnMajor() — return an object that can be iterated over with a for-each loop; iterating gives the cells of the block row by row (left to right, rows top to bottom) and column by column (top to bottom, columns left to right).

Every new iteration starts from the beginning and is independent of the others. The same block may be iterated over several times and at once, in both orders. An iteration that has run out throws NoSuchElementException. Writing with set is allowed while an iteration is in progress.

IMPORTANT:

Several sheets may exist at the same time. Every cell and every block reads and writes exactly the sheet it was taken from, so two sheets never share their numbers. A solution that does not keep to this costs 50% of the whole exercise.

A block may cover a very large part of a sheet, so an iteration must hand out its cells one at a time, rather than making them all in advance. For that reason rowMajor() and columnMajor() must NOT return a collection (Collection) of any kind, and must NOT return a ready-made iteration taken from the standard library — the iteration has to be your own. A solution that does not keep to this costs 20% of the whole exercise.

Usage example

// numbers() makes a 3x4 sheet holding 1 to 12; number(v) is String.format("%.2f", v)
Sheet sheet = numbers();

// rows 1 to 2, columns 1 to 2 - both corners included
var middle = sheet.block(1, 1, 2, 2);
System.out.println("BLOCK SIZE: " + middle.size());

// writing into a cell writes into the sheet the cell was taken from
for (var cell : middle.rowMajor()) {
  cell.set(cell.get() + 100.0);
}
System.out.println("INSIDE:  " + number(sheet.get(1, 1)) + " " + number(sheet.get(2, 2)));
System.out.println("OUTSIDE: " + number(sheet.get(0, 0)) + " " + number(sheet.get(1, 0)));

// the same four cells, given out two ways
var corner = sheet.block(0, 0, 1, 1);
List<String> byRows = new ArrayList<>();
for (var cell : corner.rowMajor()) {
  byRows.add(cell.getLabel());
}
List<String> byColumns = new ArrayList<>();
for (var cell : corner.columnMajor()) {
  byColumns.add(cell.getLabel());
}
System.out.println("ROW MAJOR:    " + String.join(" ", byRows));
System.out.println("COLUMN MAJOR: " + String.join(" ", byColumns));

// a cell of another sheet, alive at the same time, keeps to its own numbers
Sheet other = new Sheet(1, 1);
other.all().rowMajor().iterator().next().set(7.0);
System.out.println("SHEETS: " + number(sheet.get(0, 0)) + " " + number(other.get(0, 0)));

Expected output:

BLOCK SIZE: 4
INSIDE:  106.00 111.00
OUTSIDE: 1.00 5.00
ROW MAJOR:    A1 B1 A2 B2
COLUMN MAJOR: A1 A2 B1 B2
SHEETS: 1.00 7.00

Attention: all classes have visibility set to public and are in the hr.fer.oop.sheet package.
