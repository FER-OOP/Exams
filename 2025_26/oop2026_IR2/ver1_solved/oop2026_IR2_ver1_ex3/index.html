Potrebno je napisati klasu BillFileVisitor koja tijekom obilaska zadanog stabla direktorija pronalazi datoteke s računima i grupira njihove opise prema osobama kojima pripadaju.

Računom se smatra svaka datoteka čiji naziv sadrži niz znakova bill. Možete pretpostaviti da je niz bill u nazivima svih datoteka s računima uvijek napisan malim slovima te da je svaka takva datoteka tekstualna i sadrži barem jedan redak. Opis računa nalazi se u prvom retku datoteke te nije potrebno provjeravati nastavak datoteke kao ni ostatak naziva datoteke.

Sve ostale datoteke, uključujući druge tekstualne datoteke, potrebno je zanemariti.

Ime osobe određuje se prema nazivu direktorija u kojem se datoteka s računom neposredno nalazi (roditeljski direktorij). Direktorij osobe može se nalaziti na proizvoljnoj dubini unutar stabla direktorija.

Na primjer, za datoteku:

data/archive/alice_brown/internet_bill_2026.txt

ime osobe je:

alice_brown

Klasu BillFileVisitor potrebno je smjestiti u paket hr.fer.oop.

Klasa mora implementirati sučelje FileVisitor<Path> ili naslijediti klasu SimpleFileVisitor<Path>.

Potrebno je implementirati sljedeće javne metode:

  • BillFileVisitor() - konstruktor bez parametara koji inicijalizira praznu mapu za pohranu računa
  • Map<String, List<String>> getBills() - metodu koja vraća mapu pronađenih računa

Ključ mape predstavlja ime osobe, a pripadajuća vrijednost predstavlja listu prvih redaka svih datoteka s računima te osobe. Mapa mora održavati ključeve uređene prema prirodnom poretku naziva direktorija osoba. Redoslijed elemenata unutar pojedine liste nije zadan.

Ako za neku osobu nije pronađena nijedna datoteka čiji naziv sadrži bill, ta se osoba ne dodaje u mapu. Ako tijekom obilaska nije pronađena nijedna datoteka s računom, metoda getBills() vraća praznu mapu.

VAŽNO: Iz objekta tipa Path koji predstavlja putanju datoteku koja se trenutačno posjećuje može se dohvatiti putanja njezina roditeljskog direktorija.

VAŽNO: Prvi redak datoteke može se pročitati stvaranjem ulaznog toka metodom:

Files.newInputStream(file)

Dobiveni objekt tipa InputStream potrebno je dodatno „dekorirati” za čitanje teksta.

Primjer pokretanja

Zadano je sljedeće stablo direktorija:

data
├── zoe_young
│   ├── water_bill.txt
│   └── portrait.jpg
├── archive
│   ├── archive_logo.png
│   └── alice_brown
│       ├── internet_bill_2026.txt
│       └── reminders.txt
├── maya_black
│   ├── bill_electricity.txt
│   ├── phone_bill_july.txt
└── miscellaneous
    └── readme.txt

Prvi redci datoteka s računima su:

water_bill.txt:
Water bill - 45 EUR

internet_bill_2026.txt:
Internet bill - 30 EUR

bill_electricity.txt:
Electricity bill - 120 EUR

phone_bill_july.txt:
Phone bill - 25 EUR

Zadan je sljedeći kod u klasi MainClass:

public static void main(String[] args) {

    BillFileVisitor visitor = new BillFileVisitor();

    try {
        Files.walkFileTree(path, visitor);

        for (Map.Entry<String, List<String>> entry
                : visitor.getBills().entrySet()) {

            System.out.println(entry.getKey() + ":");

            List<String> sortedBills =
                    new ArrayList<>(entry.getValue());
            Collections.sort(sortedBills);

            for (String bill : sortedBills) {
                System.out.println("  " + bill);
            }
        }
    } catch (IOException e) {
        e.printStackTrace();
    }
}
