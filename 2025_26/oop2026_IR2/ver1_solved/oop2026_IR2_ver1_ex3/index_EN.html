Write the BillFileVisitor class, which traverses a given directory tree, finds files containing bills, and groups their descriptions according to the persons to whom they belong.

A bill is any file whose name contains the character sequence bill. You may assume that bill is always written in lowercase in the names of all bill files and that every such file is a text file containing at least one line. The bill description is located in the first line of the file. The file extension and the remaining parts of the filename do not need to be checked.

All other files, including other text files, must be ignored.

The person’s name is determined from the name of the directory in which the bill file is directly located (its parent directory). A person’s directory may be located at any depth within the directory tree.

For example, for the following file:

data/archive/alice_brown/internet_bill_2026.txt

the person’s name is:

alice_brown

The BillFileVisitor class must be placed in the hr.fer.oop package.

The class must either implement the FileVisitor<Path> interface or extend the SimpleFileVisitor<Path> class.

The following public constructor and method must be implemented:

  • BillFileVisitor() - a no-argument constructor that initializes an empty map for storing bills
  • Map<String, List<String>> getBills() - a method that returns the map of the discovered bills

Each map key represents a person’s name, while the corresponding value is a list containing the first lines of all bill files belonging to that person. The map must keep its keys ordered according to the natural ordering of the person directory names. The order of elements within each individual list is not specified.

If no file whose name contains bill is found for a particular person, that person must not be added to the map. If no bill files are found during the traversal, the getBills() method must return an empty map.

IMPORTANT: From a Path object representing the file currently being visited, you can obtain the path of its parent directory.

IMPORTANT: The first line of a file can be read by creating an input stream using the following method:

Files.newInputStream(file)

The resulting InputStream object must be additionally “decorated” to enable text reading.

Usage example

Consider the following directory tree:

data
├── zoe_young
│   ├── water_bill.txt
│   └── portrait.jpg
├── archive
│   ├── archive_logo.png
│   └── alice_brown
│       ├── internet_bill_2026.txt
│       └── reminders.txt
├── maya_black
│   ├── bill_electricity.txt
│   ├── phone_bill_july.txt
└── miscellaneous
    └── readme.txt

The first lines of the bill files are:

water_bill.txt:
Water bill - 45 EUR

internet_bill_2026.txt:
Internet bill - 30 EUR

bill_electricity.txt:
Electricity bill - 120 EUR

phone_bill_july.txt:
Phone bill - 25 EUR

The following code is provided in the MainClass class:

public static void main(String[] args) {

    BillFileVisitor visitor = new BillFileVisitor();

    try {
        Files.walkFileTree(path, visitor);

        for (Map.Entry<String, List<String>> entry
                : visitor.getBills().entrySet()) {

            System.out.println(entry.getKey() + ":");

            List<String> sortedBills =
                    new ArrayList<>(entry.getValue());
            Collections.sort(sortedBills);

            for (String bill : sortedBills) {
                System.out.println("  " + bill);
            }
        }
    } catch (IOException e) {
        e.printStackTrace();
    }
}

Expected output

alice_brown:
  Internet bill - 30 EUR
maya_black:
  Electricity bill - 120 EUR
  Phone bill - 25 EUR
zoe_young:
  Water bill - 45 EUR
