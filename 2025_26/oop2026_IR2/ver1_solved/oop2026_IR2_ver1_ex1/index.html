U zadatku je potrebno napisati klase kako je navedeno dijagramom klasa. U svim klasama je potrebno implementirati atribute, konstruktore i metode kako su prikazane na dijagramu klasa. Slobodno možete dodati i implementirati dodatne metode, atribute i konstruktore.

Napomena: Sve klase i sučelja imaju javnu vidljivost i nalaze se u paketu hr.fer.oop.

Legenda vidljivosti u dijagramu klasa:

Sustav modelira flotu plovila koja pristaju u maloj marini. Svako plovilo (Vessel) ima:

  • ime (name)
  • registracijsku oznaku (registrationCode)
  • duljinu u metrima (lengthMeters)
  • razinu goriva u postotku, od 0 do 100 (fuelPercent)

Stanje plovila predstavljeno je pomoću VesselStatus i može biti:

  • DOCKED (usidreno u luci)
  • AT_SEA (na moru)
  • UNDER_MAINTENANCE (na održavanju)

Osnovno pravilo određivanja stanja

Metoda getStatus() u klasi Vessel određuje stanje plovila prema razini goriva:

  • ako je razina goriva 0 ili manja → stanje je UNDER_MAINTENANCE
  • inače, ako je razina goriva manja od 15 → stanje je DOCKED
  • inače → stanje je AT_SEA

Klasa Vessel sadrži i pomoćnu metodu hasFuel(): boolean koja vraća true ako i samo ako plovilo ima goriva (razina goriva je veća od 0). Ta metoda nije dio javnog API-ja (ne postoji u vanjskom sučelju za korisnike klase), nego služi isključivo unutar hijerarhije klasa - koristi je getStatus() u klasi Vessel, a preporučeno ju je koristiti i u podklasama kad god trebaju provjeriti ima li plovilo goriva.

Sučelje SeaWorthy

Sučelje SeaWorthy deklarira metodu canSail(): boolean koja provjerava može li plovilo trenutno isploviti. Svaka konkretna podklasa implementira ovu metodu na svoj način (vidi opise podklasa niže).

SailingBoat (jedrilica)

  • dodatno ima kapacitet posade crewCapacity (broj članova posade potrebnih za plovidbu)
  • metoda canSail() vraća true ako i samo ako plovilo ima barem jednog člana posade (jedrilica ne treba gorivo jer plovi na vjetar, ali treba posadu)

FishingTrawler (koćarica)

  • dodatno ima kapacitet skladišnog prostora za ulov cargoCapacityKg i trenutnu količinu ulova currentCatchKg (na početku 0)
  • metoda addCatch(double kg) dodaje ulov u skladište ako je predana količina veća od 0 i ako zbroj trenutnog ulova i te količine ne prelazi kapacitet skladišta. Ako bilo koji od ta dva uvjeta nije zadovoljen, metoda ne mijenja stanje objekta i vraća false. Inače povećava trenutni ulov za predanu količinu i vraća true.
  • metoda canSail() vraća true ako i samo ako skladište nije puno (trenutni ulov je manji od kapaciteta) i plovilo ima goriva
  • metoda getStatus(): prvo se odredi osnovno stanje prema pravilu klase Vessel. Ako je to stanje AT_SEA, a skladište je gotovo puno (trenutni ulov iznosi barem 90% kapaciteta), koćarica se mora vratiti u luku pa metoda vraća DOCKED. U svim ostalim slučajevima vraća se to osnovno stanje.

IndustrialTrawler (industrijska koćarica)

IndustrialTrawler nasljeđuje FishingTrawler (a ne izravno Vessel).

  • dodatno ima broj članova posade crewSize
  • metoda canSail() vraća true ako i samo ako vrijede uvjeti naslijeđeni iz klase FishingTrawler i posada broji barem 3 člana (sigurnosni propis: industrijska koćarica ne smije isploviti s premalo posade)
  • metoda getStatus(): ako posada ima manje od 3 člana, metoda vraća UNDER_MAINTENANCE bez obzira na gorivo ili popunjenost skladišta (brod se zadržava u luci dok se ne popuni posada). Inače vraća stanje koje bi vratila naslijeđena metoda iz klase FishingTrawler.

ResearchVessel (istraživački brod)

  • dodatno ima oznaku je li trenutno u tijeku kalibracija znanstvene opreme calibrationInProgress
  • metode startCalibration() i stopCalibration() postavljaju calibrationInProgress na true odnosno false
  • metoda canSail() vraća true ako i samo ako kalibracija trenutno nije u tijeku i plovilo ima goriva
  • metoda getStatus(): ako je kalibracija trenutno u tijeku, metoda vraća UNDER_MAINTENANCE bez obzira na razinu goriva. Inače vraća osnovno stanje prema pravilu klase Vessel.

Napomena: Sve ostale detalje (nasljeđivanje, sučelja, modifikatore vidljivosti i metode) potrebno je implementirati prema UML dijagramu.

Primjer korištenja:

// SAILING BOAT
SailingBoat boat = new SailingBoat("Adriana", "ST-101", 8.5, 60.0, 2);
System.out.println("Can sail: " + boat.canSail());          // true (crewCapacity >= 1)
System.out.println("Status: " + boat.getStatus());          // AT_SEA (fuelPercent >= 15)

// FISHING TRAWLER
FishingTrawler trawler = new FishingTrawler("Neptun", "FT-207", 14.0, 80.0, 500.0);
System.out.println("Adding 200kg: " + trawler.addCatch(200.0));   // true
System.out.println("Adding 250kg: " + trawler.addCatch(250.0));   // true (currentCatch = 450kg, >= 90% of 500kg)
System.out.println("Status: " + trawler.getStatus());             // DOCKED (skladište gotovo puno)
System.out.println("Can sail: " + trawler.canSail());             // true (450kg < 500kg kapaciteta)

// RESEARCH VESSEL
ResearchVessel vessel = new ResearchVessel("Argus", "RV-303", 22.0, 90.0, false);
System.out.println("Status before calibration: " + vessel.getStatus());  // AT_SEA
vessel.startCalibration();
System.out.println("Status during calibration: " + vessel.getStatus()); // UNDER_MAINTENANCE
System.out.println("Can sail during calibration: " + vessel.canSail()); // false

// INDUSTRIAL TRAWLER
IndustrialTrawler small = new IndustrialTrawler("Titan", "IT-501", 20.0, 70.0, 1000.0, 2);
System.out.println("Can sail (crewSize=2): " + small.canSail());   // false (crewSize < 3)
System.out.println("Status (crewSize=2): " + small.getStatus());   // UNDER_MAINTENANCE

IndustrialTrawler full = new IndustrialTrawler("Titan", "IT-501", 20.0, 70.0, 1000.0, 5);
System.out.println("Can sail (crewSize=5): " + full.canSail());          // true
System.out.println("Status before big catch: " + full.getStatus());     // AT_SEA
full.addCatch(950.0);
System.out.println("Status after 950kg catch: " + full.getStatus());    // DOCKED (storage >= 90%)
