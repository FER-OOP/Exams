U zadatku su dane apstraktna klasa Pet i konkretna (neapstraktna) klasa Cat, kao i klasa Main, a potrebno je napisati konkretne klase Dog, Parrot i Dolphin te tipove SwimmerPet i SmartPet za koje je potrebno odlučiti trebaju li biti sučelja ili klase. Osim toga, potrebno je uspostaviti hijerarhiju klasa i implementirati odgovarajuća sučelja u klasama. Sve konkretne klase (Cat, Dog, Parrot i Dolphin) imaju klasu Pet kao nadklasu, ali ne nužno kao svoju direktnu nadklasu.

NAPOMENA: Klase Pet i Cat nije dozvoljeno mijenjati radi ispravnog bodovanja rješenja.

Objekti tipa Pet posjeduju sreću (happiness) tipa int koja se postavlja prilikom stvaranja objekta, može se povećati za 5 igranjem (tj. pozivanjem metode void play()). Trenutno stanje sreće može se dohvatiti pozivanjem gettera int getHappiness(), ali ne smije postojati setter za njeno postavljanje.

Objekti tipa Parrot i Dolphin predstavljaju pametne ljubimce te su stoga tipa SmartPet. Objekti tipa SmartPet posjeduju broj naučenih trikova (tricksLearned) tipa int koji se postavlja prilikom stvaranja objekta, može se povećati učenjem trika, tj. pozivanjem metode void learnTrick(), a trenutno stanje naučenih trikova može se dohvatiti pozivanjem gettera int getTricksLearned(). Analogno sreći (happiness) ne smije postojati setter za broj naučenih trikova. Dodatno, kada se pametni ljubimci igraju (tj. pozovu play()), zaborave jedan trik, a prilikom učenja novih trikova njihova sreća se smanjuje što će biti objašnjeno kasnije. Broj naučenih trikova ne može postati negativan, već mu je najmanja vrijednost jednaka 0.

Svaki objekt tipa Dog ili Dolphin je ljubimac plivač tipa SwimmerPet. Ljubimci plivači troše sreću plivanjem, tj. pozivanjem metode void swim().

Konkretne klase imaju jedan konstruktor, a primjer njihova pozivanja prikazan je u isječku dane metode main u klasi Main:

Cat cat = new Cat("Mittens", 50); // name, happiness
Dog dog = new Dog("Buddy", 60); // name, happiness
Parrot parrot = new Parrot("Polly", 70, 0); // name, happiness, tricksLearned
Dolphin dolphin = new Dolphin("Flippy", 80, 2); // name, happiness, tricksLearned

Nad svakim objektom bilo kojeg od ovih 7 tipova (Cat, Dog, Parrot, Dolphin, Pet, SwimmerPet i SmartPet) se mogu pozvati sljedeće općenite metode:

  • String getName() – vraća ime postavljeno u konstruktoru
  • int getHappiness() – vraća trenutno stanje sreće
  • void play() – povećava sreću za objekte tipa Pet, a dodatno smanjuje broj trikova za objekte tipa SmartPet kako je prethodno opisano

Sljedeće specifične metode mogu se pozvati na objektima tipa Cat:

  • void chaseLaser() – povećava sreću za 4

Sljedeće specifične metode mogu se pozvati na objektima tipa Dog:

  • void fetchBall() – povećava sreću za 6
  • void swim() – smanjuje sreću za 3

Sljedeće specifične metode mogu se pozvati na objektima tipa Parrot:

  • int getTricksLearned() – vraća trenutno stanje naučenih trikova
  • void learnTrick() – povećava broj trikova za 1 i smanjuje sreću za 2
  • void sing() – povećava sreću za 4

Sljedeće specifične metode mogu se pozvati na objektima tipa Dolphin:

  • int getTricksLearned() – vraća trenutno stanje naučenih trikova
  • void learnTrick() – povećava broj trikova za 1 i smanjuje sreću za 4
  • void swim() – smanjuje sreću za 1

NAPOMENA: Sve klase i sučelja trebaju imati vidljivost postavljenu na public i nalaziti se u paketu hr.fer.oop.
