U zadatku je potrebno nadopuniti programski kod klasa CompressingInputStream i DecompressingOutputStream. Na mjestima na kojima je potrebno dodati programski kod se nalazi komentar //TODO.

Klasa CompressingInputStream direktno nasljeđuje apstraktnu klasu InputStream i koristi se kao dekorator nad drugim objektom koji također nasljeđuje InputStream.
Služi za komprimiranje pročitanih bajtova tako da svaki niz uzastopnih istih bajtova iz dekoriranog toka zamjenjuje s točno dva bajta:

  • prvi bajt je vrijednost koja se ponavlja,
  • drugi bajt označava broj uzastopnih ponavljanja te vrijednosti.

Klasa DecompressingOutputStream direktno nasljeđuje apstraktnu klasu OutputStream i koristi se kao dekorator nad drugim objektom koji također nasljeđuje OutputStream.
Služi za dekomprimiranje bajtova koji se zapisuju tako da svaki zapisani par bajtova interpretira kao:

  • prvi bajt – vrijednost koja se treba ponavljati,
  • drugi bajt – broj ponavljanja,

i na temelju njih upisuje niz uzastopnih instanci prvog bajta u izlazni tok, u dužini koja odgovara vrijednosti drugog bajta.

NAPOMENA: Klase CompressingInputStream i DecompressingOutputStream ne smiju biti finalne tj. moraju se moći naslijediti radi ispravnog bodovanja rješenja.

Primjer korištenja ovih klasa prikazan je u sljedećem isječku dane metode main u klasi Main:

//input stream demo
byte[] data = new byte[]{0x10, 0x10, 0x10, 0x20, 0x20, 0x30, 0x30, 0x30, 0x30};
        
try (ByteArrayInputStream source = new ByteArrayInputStream(data); InputStream cis = new CompressingInputStream(source)) {
    int b;
    //prints 10 03 20 02 30 04
    while ((b = cis.read()) != -1) {
        //read each byte of the input stream and write it to the console
        System.out.printf("%02X ", b);
    }
    System.out.println("");
} catch (IOException ex) {
    ex.printStackTrace();
}

        
//output stream demo
byte[] compressedData = new byte[]{0x10, 0x03, 0x20, 0x02, 0x30, 0x04};

try (ByteArrayOutputStream destination = new ByteArrayOutputStream(); OutputStream dos = new DecompressingOutputStream(destination)) {
    for (byte b : compressedData) {
        //write each byte of the output stream
        dos.write(b);
    }

    //prints 10 10 10 20 20 30 30 30 30
    for (byte rb : destination.toByteArray()) {
        System.out.printf("%02X ", rb);
    }
} catch (IOException ex) {
    ex.printStackTrace();
}

Ispravan rezultat izvođenja dane metode main u klasi Main:

10 03 20 02 30 04 
10 10 10 20 20 30 30 30 30
