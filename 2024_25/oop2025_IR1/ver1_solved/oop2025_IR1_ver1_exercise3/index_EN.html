In this assignment, you are required to complete the implementation of the classes CompressingInputStream and DecompressingOutputStream. The places where code needs to be added are marked with the comment //TODO.

The CompressingInputStream class directly extends the abstract InputStream class and is used as a decorator for another object that also extends InputStream.
It compresses the bytes read so that each sequence of consecutive identical bytes from the decorated stream is replaced by exactly two bytes:

  • the first byte is the repeated value,
  • the second byte indicates the exact number of consecutive repetitions of that value.

The DecompressingOutputStream class directly extends the abstract OutputStream class and is used as a decorator for another object that also extends OutputStream.
It decompresses bytes being written so that each pair of bytes written to it is interpreted as:

  • the first byte – the value to be repeated,
  • the second byte – the number of repetitions,

and, based on these, writes a sequence of consecutive instances of the first byte to the underlying output stream, with a length corresponding to the second byte’s value.

NOTE: The CompressingInputStream and DecompressingOutputStream classes must not be declared as final; they must be inheritable to ensure correct grading of the solution.

An example usage of these classes is shown in the following snippet from the main method in the Main class:

//input stream demo
byte[] data = new byte[]{0x10, 0x10, 0x10, 0x20, 0x20, 0x30, 0x30, 0x30, 0x30};
        
try (ByteArrayInputStream source = new ByteArrayInputStream(data); InputStream cis = new CompressingInputStream(source)) {
    int b;
    //prints 10 03 20 02 30 04
    while ((b = cis.read()) != -1) {
        //read each byte of the input stream and write it to the console
        System.out.printf("%02X ", b);
    }
    System.out.println("");
} catch (IOException ex) {
    ex.printStackTrace();
}

        
//output stream demo
byte[] compressedData = new byte[]{0x10, 0x03, 0x20, 0x02, 0x30, 0x04};

try (ByteArrayOutputStream destination = new ByteArrayOutputStream(); OutputStream dos = new DecompressingOutputStream(destination)) {
    for (byte b : compressedData) {
        //write each byte of the output stream
        dos.write(b);
    }

    //prints 10 10 10 20 20 30 30 30 30
    for (byte rb : destination.toByteArray()) {
        System.out.printf("%02X ", rb);
    }
} catch (IOException ex) {
    ex.printStackTrace();
}

The expected correct output of the provided main method in the Main class is:

10 10 10 20 20 30 30 30 30
