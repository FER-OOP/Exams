In this assignment, you are required to complete the source code of the WeatherRecord and Lambdas classes.

The WeatherRecord class models weather records consisting of five private attributes:

  • String city – represents the name of the city,
  • LocalDate date – represents the date of the record,
  • double minTemperature – represents the minimum temperature on that day,
  • double maxTemperature – represents the maximum temperature on that day, and
  • long dailyRainfall – represents the daily rainfall amount on that day.

In this class, you need to complete the following three parts of the code, marked with the //TODO comment:

  1. complete the code for attribute comparators for the minTemperature, maxTemperature, and dailyRainfall attributes, which will be used to sort weather records,
  2. complete the implementation of the equals method, and
  3. complete the implementation of the hashCode method.

NOTE: When implementing the equals and hashCode methods, you must first determine which set of attributes defines the uniqueness of a weather record and use only those attribute values in your implementation.

In the Lambdas class, you need to complete the static attributes getFilteredAndSortedFromCollection and getFilteredAndSortedFromMap, as shown in the following code snippet:

public static TriFunction<Collection<WeatherRecord>, Predicate<WeatherRecord>, Comparator<WeatherRecord>, Collection<WeatherRecord>> getFilteredAndSortedFromCollection = null; //TODO

public static TriFunction<Map<Integer, Collection<WeatherRecord>>, Predicate<WeatherRecord>, Comparator<WeatherRecord>, Collection<WeatherRecord>> getFilteredAndSortedFromMap = null; //TODO

NOTES: Both static attributes must be implemented as lambda expressions using the Java Stream API (i.e., collection streams). It is not necessary to catch or handle exceptions during implementation. The Lambdas class should be placed in the hr.fer.oop package, and both the class and its static attributes should have public visibility.

Both static attributes are of type TriFunction, i.e., a function that accepts three arguments and returns a result, and is therefore parameterized with four types, namely (from left to right) the three argument types and the result type. The TriFunction functional interface does not exist in the Java API; the code for this interface is provided in the assignment.

Static attribute getFilteredAndSortedFromCollection

This TriFunction, given the input arguments 1) a collection of weather records, 2) a predicate on weather records, and 3) a comparator for weather records, should return an output collection of weather records consisting of the filtered and sorted version of the input collection. Filtering should be done such that only weather records satisfying the given predicate remain in the output collection. Sorting should be done using the given comparator.

Static attribute getFilteredAndSortedFromMap

This TriFunction, given the input arguments 1) a map of weather records of type Map<Integer, Collection<WeatherRecord>>, 2) a predicate on weather records, and 3) a comparator for weather records, should return an output collection of weather records consisting of the filtered and sorted combination of all weather records from the input map. From the input map, which contains collections of weather records (values of type Collection<WeatherRecord>) indexed by year (keys of type Integer), you must create a unified collection stream of all weather records. This unified stream of weather records should then be filtered using the predicate, sorted using the comparator, and finally collected into the output collection of weather records.

NOTE: The input data is loaded into the Map<Integer, Collection<WeatherRecord>> from a CSV file using the static attribute loadFromStream from the Lambdas class, which you do not need to implement, as its code is provided in the assignment.
