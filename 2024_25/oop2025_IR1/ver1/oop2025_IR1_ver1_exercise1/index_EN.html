In the assignment, an abstract class Pet and a concrete (non-abstract) class Cat, as well as a class Main, are given. The goal is to write concrete classes Dog, Parrot, and Dolphin, as well as the types SwimmerPet and SmartPet for which it is necessary to decide whether they should be interfaces or classes. Additionally, it is necessary to establish a class hierarchy and implement appropriate interfaces in the classes. All concrete classes (Cat, Dog, Parrot, and Dolphin) have the class Pet as a superclass, but not necessarily as their direct superclass.

NOTE: Classes Pet and Cat must not be changed for correct scoring of the solution.

Objects of type Pet possess happiness (happiness) of type int which is set when the object is created, can be increased by 5 by playing (i.e., calling the method void play()), and the current happiness state can be retrieved by calling the getter int getHappiness(). There must not be a setter for happiness.

Objects of type Parrot and Dolphin are smart pets and therefore also of type SmartPet. Objects of type SmartPet possess tricks learned (tricksLearned) of type int which is set when the object is created, can be increased by learning a trick, i.e., calling the method void learnTrick(), and the current number of learned tricks can be retrieved by calling the getter int getTricksLearned(). There must not be a setter for tricks learned. Additionally, when smart pets play (i.e., call play()) they forget one trick, and while they are learning new tricks their happiness decreases. The number of learned tricks cannot become negative, and its minimum value is 0.

Every object of type Dog or Dolphin is a swimmer pet of type SwimmerPet. Swimmer pets spend happiness by swimming, i.e., calling the method void swim().

Concrete classes have a single constructor, and an example of their invocation is shown in the snippet of the given main method in the Main class:

Cat cat = new Cat("Mittens", 50); // name, happiness
Dog dog = new Dog("Buddy", 60); // name, happiness
Parrot parrot = new Parrot("Polly", 70, 0); // name, happiness, tricksLearned
Dolphin dolphin = new Dolphin("Flippy", 80, 2); // name, happiness, tricksLearned

The following general methods can be called on any object of these 7 types (Cat, Dog, Parrot, Dolphin, Pet, SwimmerPet, and SmartPet):

  • String getName() - returns the name which is set in the constructor
  • int getHappiness() - returns the current happiness state
  • void play() - increases happiness for objects of type Petand additionaly decreases tricks learned for objects of type SmartPet as previously mentioned

The following specific methods can also be called on objects of type Cat:

  • void chaseLaser() - increases happiness by 4

The following specific methods can also be called on objects of type Dog:

  • void fetchBall() - increases happiness by 6
  • void swim() - decreases happiness by 3

The following specific methods can also be called on objects of type Parrot:

  • int getTricksLearned() - returns the current number of tricks learned
  • void learnTrick() - increases tricks learned by 1 and decreases happiness by 2
  • void sing() - increases happiness by 4

The following specific methods can also be called on objects of type Dolphin:

  • int getTricksLearned() - returns the current number of tricks learned
  • void learnTrick() - increases tricks learned by 1 and decreases happiness by 4
  • void swim() - decreases happiness by 1

NOTE: All classes and interfaces should have their visibility set to public and belong to the hr.fer.oop package.
