In this assignment, you need to complete the implementation of the MyPriorityQueue class, which models a sorted collection that can contain duplicates, but cannot contain null elements.

The parameterized class MyPriorityQueue<E> extends the TreeMap<E, Integer> class and implements the given interface hr.fer.oop.PriorityQueue<E>. The backing map stores key–value pairs, where the key of type E represents an element added to the collection, and the value of type Integer indicates how many identical elements remain in the collection.

Unlike the java.util.PriorityQueue<E> class from the Java API, the given interface hr.fer.oop.PriorityQueue<E> models a simpler collection with only four methods:

  • void add(E e) - adds element e to the collection or throws a java.lang.NullPointerException if the element is null
  • int size() - returns the total number of elements stored in the collection
  • E poll() - retrieves the first (by sort order) element of the collection and removes it from the collection
  • Iterator<E> iterator() - returns an iterator over the collection

To better understand how these methods work, see the usage example at the end of the assignment.

In the MyPriorityQueue<E> class, you need to complete the implementation of two constructors and four methods from the hr.fer.oop.PriorityQueue<E> interface. The no-argument constructor MyPriorityQueue() is used when the collection elements should be sorted in their natural order, while the constructor MyPriorityQueue(Comparator<? super E> comparator) is used when the collection elements should be sorted using the comparator provided as an argument.
