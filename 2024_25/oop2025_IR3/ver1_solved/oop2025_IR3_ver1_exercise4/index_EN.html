Watch, and various bags (Bag) are Wearable things. Weight, volume, and unique identifier of a thing are available using following methods:

  • int getVolume()
  • int getWeight()
  • String getId()

Bags are further defined on backpacks (Backpack) and purses (Purse). Beside what is defined with Wearable, bags additionaly have dominant material (material:MaterialType) where MaterialType is limited on: Leather, Wood, Plastic, Metal, Gold, Silver, Glass, Cotton, Wool, Rubber, Paper, and Fabric, but bags cannot be made of metal, gold, silver, or glass, and any attempt to create an instance of such back would yield to IllegalArgumentException. Backpack additionally have maximum screen size of a laptop, if it is possible to a laptop inside (laptopSize:OptionalInt).

The order of the arguments in constructor is always such that first arguments are identifier, volume, and weight, followed by other things, e.g. laptop size should be the last argument.

Wearable thigs are stored inside a Storage. Storages are divided on FixedStorage and WearableStorage, and creation of a storage that is not neither fixed nor wearable is not possible. Bag is a wearable storage. Storages have their material (material:MaterialType) and (capacity:int) (i.e. volume od wearable things that be stored in the storage). The order in constructor is material, and then capacity. Wearable things in Storage should be stored in a variable defined as private final List<Wearable> list = new LinkedList<>();

For the sake of the simplicity, capacity of the bag is same as its volume.

Storage should have the following methods:

  • boolean addWearable(Wearable thing) - returns true if the thing is added. It should be added if there is enough capacity and if such id does not alredy exists.
  • boolean removeWearable(String wearableId) - returns true if wearable with that id exists, and it removes it from the storage
  • List<Wearable> wearables() - return lists of wearables inside the storage. The returned list must be unmodifiable
  • int getWeight() //returns total weight of things in the storage

It is not allowed to put a backpack in a purse even if capacity is large enough. Attempt to do that should throw IllegalArgumentException.

All atributes should be marked as final, and initialized in constructors. Their values should be accessible using getters using standard naming for getters

All classes, interfaces, and enumerations are defined in package hr.fer.oop.wearables.
