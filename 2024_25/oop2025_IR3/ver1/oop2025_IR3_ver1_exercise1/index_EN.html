The map of type Map<String, Set<String>> has botanical genera names as keys, and each key is paired with set of species names. For example, if we print the map content (by printing key and value separated by :), obtained from the sample file, the output would be like the following one.

Abies : [alba]
Abutilon : [theophrasti]
Acalypha : [australis, rhomboidea, virginica]
Acanthus : [balcanicus, mollis, spinosissimus]
Acer : [campestre, monspessulanum, negundo, obtusatum, opalus, platanoides, pseudoplatanus, saccharinum, tataricum]
Aceras : [anthropophorum]
Achillea : [abrotanoides, ageratum, aspleniifolia, clavennae, coarctata, collina, crithmifolia, distans, ligustica, millefolium, nobilis, odorata, pannonica, pratensis, ptarmica, setacea, tomentosa, virescens]
...

Different streams can be created from the map, e.g., stream of values (of type Stream<Set<String>>) or stream of map entries (type is Stream<Map.Entry<String,Set<String>>>)

Your task is to implement three methods in class Task

 int count(Stream<Set<String>> taxa)

The method has stream of the map values, and should retun how many different species exist in the map. For example, the first entry in the stream is the set [alba], then the set [theophrasti], followed by the sat [australis, rhomboidea, virginica], ... If these three sets were the only values in the map, the resulst would be 5.

  Stream<Pair<String, Integer>> genera(Stream<Entry<String, Set<String>>> taxa)

The method should return stream of pairs (Pair is already defined as a records) in which the first element of the pair is genus name, a the seconda is number of species belonging to the genus. In the provided sample Abutilon has 1, and Acalypha 3 species.

  Stream<String> species(Stream<Entry<String, Set<String>>> entries)

The method should should retuen stream of string with full taxon names (i.e., genus name and species name separated by space). For the provided sample data, such stream will contain the following strings Abies alba, Abutilon theophrasti, Acalypha australis, Acalypha rhomboidea, ...
