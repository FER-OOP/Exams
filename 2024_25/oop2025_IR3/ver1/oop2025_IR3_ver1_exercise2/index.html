Vaš zadatak je dovršiti implementaciju sučelja Iterable<Pair<Character, Integer>> u klasi IterableString. Ideja ove klase je da se može iterirati po znakovima nekog stringa, ali da je svaki element u iteriranju ne samo jedan znak, već par koji se sastoji od znakovnog omotača (tip Character) i cjelobrojnog omotača (tip Integer).

Koji broj će biti uparen s kojim znakom ovisi o iteratoru koji je predan kao drugi argument u konstruktoru. Prilikom vraćanja svakog novog para pomoću primljenog iteratora treba uzeti sljedeći broj ako postoji, a ako ga nema treba iskoristiti onaj koji je zadnji upotrijebljen u toj instanci iteratora.

Navedeno se može ilustrirati u sljedećem programskom odsječku.

List<Integer> ids = List.of(1, 2, 3);
IterableString s = new IterableString("ABCDE", ids.iterator());
for(Pair<Character, Integer> p : s) {
  System.out.println(p.first() + " -> " + p.second());
} //output should be (in each line) A -> 1, B -> 2, C -> 3, D -> 3, E -> 3
System.out.println();

Iterator nastao iz liste [1, 2, 3] se "potrošio" redom za slova A, B i C, pa su D i E bili upareni s onim koji je zadnji korišten, a to je broj 3.

Broj iz predanog iteratora se smije "potrošiti" samo za nastajanje novog para. Primjerice, pogleda li se sljedeći odsječak u kojem je iteriranje po s2 prestalo nakon prvog znaka, može se primijetiti da 3 nije "potrošen" te se koristi kod s3.

Iterator<Integer> it = List.of(1, 2, 3, 4).iterator();
IterableString s1 = new IterableString("K", it);
IterableString s2 = new IterableString("LM", it);
IterableString s3 = new IterableString("NOP", it);	
for(Pair<Character, Integer> p : s1) {
  System.out.println(p.first() + " -> " + p.second()); // K -> 1			
}
for(Pair<Character, Integer> p : s2) {
  System.out.println(p.first() + " -> " + p.second()); // L -> 2
  break; //after the first character!
}
for(Pair<Character, Integer> p : s3) {
  System.out.println(p.first() + " -> " + p.second()); // N -> 3, O -> 4, P -> 4			
}

Ako je iterator prazan ili već cijeli iskorišten i prije nego što je prvo slovo dodao u par, onda "broj" u tom paru treba biti null, jer nema prethodno korištenog.

IterableString s4 = new IterableString("R", it);
for(Pair<Character, Integer> p : s4) {
  System.out.println(p.first() + " -> " + p.second()); // R -> null			
}

Iterator je zadan u konstruktoru, pa ako se više puta iterira po istom IterableStringu koristit će se isti iterator brojeva što se vidi iz sljedećg primjera.

IterableString s5 = new IterableString("ABC", List.of(1, 2, 3, 4, 5).iterator());
for(Pair<Character, Integer> p : s5) {
  System.out.println(p.first() + " -> " + p.second()); // A -> 1, B -> 2, C -> 3			
}
for(Pair<Character, Integer> p : s5) {
  System.out.println(p.first() + " -> " + p.second()); // A -> 4, B -> 5, C -> 5			
}
