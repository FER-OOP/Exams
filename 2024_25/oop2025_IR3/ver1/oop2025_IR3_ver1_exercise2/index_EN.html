Your task is to finish implementation of the class IterableString by correctly implementing Iterable<Pair<Character, Integer>> interface. The idea of the interface implementaion is to be able to iterate string characters in such way that each Character is paired with an Integer.

Which number will be used in pairing with a character depends on the state of an Iterator<Integer> instance, sent as the second argument in the constructor of IterableString. If the iterator instance has no more elements then the last used number should be used. This behaviour can be seen in the following example.

List<Integer> ids = List.of(1, 2, 3);
IterableString s = new IterableString("ABCDE", ids.iterator());
for(Pair<Character, Integer> p : s) {
  System.out.println(p.first() + " -> " + p.second());
} //output should be (in each line) A -> 1, B -> 2, C -> 3, D -> 3, E -> 3
System.out.println();

Iterator created from the list [1, 2, 3] has been "used" for A, B, and C respectivelly. Therefore D and E are paired with the last used number (3).

A number from the iterator should be taken only when new pair is created. For example, in the next excerpt, iterating through s2 stops after the first element, which means that number 3 is not consumed, and has been paired with N from s3.

Iterator<Integer> it = List.of(1, 2, 3, 4).iterator();
IterableString s1 = new IterableString("K", it);
IterableString s2 = new IterableString("LM", it);
IterableString s3 = new IterableString("NOP", it);	
for(Pair<Character, Integer> p : s1) {
  System.out.println(p.first() + " -> " + p.second()); // K -> 1			
}
for(Pair<Character, Integer> p : s2) {
  System.out.println(p.first() + " -> " + p.second()); // L -> 2
  break; //after the first character!
}
for(Pair<Character, Integer> p : s3) {
  System.out.println(p.first() + " -> " + p.second()); // N -> 3, O -> 4, P -> 4			
}

If the iterator is empty or already consumed before the first character has been paired then "number" in the pair should be null, because there is no previously used number.

IterableString s4 = new IterableString("R", it);
for(Pair<Character, Integer> p : s4) {
  System.out.println(p.first() + " -> " + p.second()); // R -> null			
}

Iterator is set in the constructor. Therefore, if we iterate same IterableString twice or more times, same iterator is used, and it may happen that it would be "consumed", as demonstrated in the next example.

IterableString s5 = new IterableString("ABC", List.of(1, 2, 3, 4, 5).iterator());
for(Pair<Character, Integer> p : s5) {
  System.out.println(p.first() + " -> " + p.second()); // A -> 1, B -> 2, C -> 3			
}
for(Pair<Character, Integer> p : s5) {
  System.out.println(p.first() + " -> " + p.second()); // A -> 4, B -> 5, C -> 5			
}
