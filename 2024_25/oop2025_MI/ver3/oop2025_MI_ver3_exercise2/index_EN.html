In the exercise, you have to to implement a bank account with associated elements.

The default class is MyList, which is similar to the list we did on the recapitulation. It works with objects (class Object) which should be parameterized with generics. When doing so, you might get a compiler warning like this:

Compile errors/warnings:
hr.fer.oop.MyList:15: warning: [unchecked] unchecked cast

You can ignore this or you can add the following code before that line and that warning should disappear.

@SuppressWarnings("unchecked")

You need to add a getCopy method to the list that returns a copy of the list.

The UML class diagram shows the classes that need to be created (most of the classes are given to you, so the remaining classes are: Transaction, BankAccount and BankException). In addition, you need to modify the existing code of the MyList class and add the getCopy method, which returns a copy of the list. In all classes, you need to implement attributes (member variables), constructors and methods as shown in the diagram. You are free to add and implement additional methods, attributes and constructors.

The validation rules listed below should throw an appropriate exception if not met. The BankException class is an unchecked exception. In validations, you don't need to write the exact text in exceptions because that text is not checked. Each class should throw an exception that is specific to that class, for example, the BankAccount class throws BankAccountException in validation code.

The IBAN class represents a bank account number. The built-in validation rules are (this is a given):

  • IBAN must not be null
  • IBAN must have exactly 34 characters
  • IBAN must contain only letters and digits

The Transaction class represents a single transaction. The transaction type is defined in the TransactionType enumeration. There are 3 transaction types: deposit - deposit to an account (e.g. cash deposit), withdrawal - withdrawal from an account (e.g. using an ATM), and transfer - transfer from one account to another. The rules for validating a transaction are:

  • amountInHundredths must be greater than zero. Example amount: 100.10 is stored as the value 10010. The exercise only use integer values, so no additional conversion is required.
  • type (transaction type) must not be null.
  • At least one of sourceAccount or destinationAccount must not be null.
  • sourceAccount and destinationAccount must not be the same.
  • For transaction types WITHDRAWAL or TRANSFER, sourceAccount must not be null.
  • For transaction types DEPOSIT or TRANSFER, destinationAccount must not be null.

In the BankAccount class, all transactions are stored in the list. The getBalanceInHundredths method should calculate the current balance by going through all transactions. The assumption is that at the beginning the state is 0. Using the addTransaction method, transactions are added to the list (pay attention to which transactions can be added). The getTransactions method returns a list that is a copy of the internal transactions. The deposit, withdraw and transferTo methods check the conditions and add the transaction to the list (they use the addTransaction method). The rules for validation are:

  • IBAN must not be null.
  • Transactions added to the account must not be null.
  • Transactions to be added must include the IBAN of the account that is either the source or destination account.
  • Deposit:
    • The deposit amount must be greater than zero.
  • Withdrawal:
    • The withdrawal amount must not exceed the account balance.
  • Transfer:
    • The transfer amount cannot exceed the account balance.
    • The transfer transaction is added to both the source and destination accounts.

Note: all classes are in the hr.fer.oop.bank package and are public, only the MyList class is package private.

Example of use:

package hr.fer.oop.bank;

public class Main {

  public static void main(String[] args) {
    // Create IBANs
    IBAN iban1 = new IBAN("HR12345678901234567890123456789012");
    IBAN iban2 = new IBAN("HR98765432109876543210987654321098");

    // Create Bank Accounts
    BankAccount account1 = new BankAccount(iban1);
    BankAccount account2 = new BankAccount(iban2);

    // Deposit money into account1
    account1.deposit(10000); // Deposit 100.00 in hundredths
    System.out.println("Account 1 balance after deposit: " + account1.getBalanceInHundredths());

    // Withdraw money from account1
    account1.withdraw(5000); // Withdraw 50.00 in hundredths
    System.out.println("Account 1 balance after withdrawal: " + account1.getBalanceInHundredths());

    // Transfer money from account1 to account2
    account1.transferTo(3000, account2); // Transfer 30.00 in hundredths
    System.out.println("Account 1 balance after transfer: " + account1.getBalanceInHundredths());
    System.out.println("Account 2 balance after receiving transfer: " + account2.getBalanceInHundredths());

    // Print transactions for account1
    System.out.println("\nAccount 1 transactions:");
    MyList<Transaction> transactions = account1.getTransactions();
    for (int i = 0; i < transactions.size(); i++) {
      Transaction transaction = transactions.elementAt(i);
      System.out.println(transaction.getType() + " - " + transaction.getAmountInHundredths());
    }

    // Print transactions for account2
    System.out.println("\nAccount 2 transactions:");
    transactions = account2.getTransactions();
    for (int i = 0; i < transactions.size(); i++) {
      Transaction transaction = transactions.elementAt(i);
      System.out.println(transaction.getType() + " - " + transaction.getAmountInHundredths());
    }

    // Some exceptional cases
    System.out.println("\nTesting exceptional cases:");
    System.out.println("Testing invalid IBAN:");
    try {
      new IBAN("INVALID_IBAN"); // Less than 34 characters
    } catch (IbanException e) {
      System.out.println("Exception: " + e);
    }

    System.out.println("Testing invalid transaction:");
    try {
      new Transaction(
        10000,
        TransactionType.DEPOSIT,
        null,
        null
      );
    } catch (TransactionException e) {
      System.out.println("Exception: " + e);
    }

    System.out.println("Testing withdrawal exceeding balance:");
    try {
      account1.withdraw(20000); // Attempt to withdraw more than the balance
    } catch (BankAccountException e) {
      System.out.println("Exception: " + e);
    }

    System.out.println("Testing transfer exceeding balance:");
    try {
      account1.transferTo(20000, account2); // Attempt to transfer more than the balance
    } catch (BankAccountException e) {
      System.out.println("Exception: " + e);
    }
  }
}
