U zadatku je potrebno implementirati bankovni račun sa pripadajućim elementima.

Zadana je klasa MyList koja je slična listi koju smo radili na rekapitulaciji. Ona radi s objektima (klasa Object) koju treba parametrizirati s genericima. Prilikom toga ćete možda dobiti upozorenje kod prevođenja kao što je ovo:

Compile errors/warnings:
hr.fer.oop.MyList:15: warning: [unchecked] unchecked cast

To možete ignorirati ili možete dodati prije toga retka sljedeći kod pa bi to upozorenje trebalo nestati.

@SuppressWarnings("unchecked")

U UML dijagramu klasa su prikazane klase koje je potrebno napraviti (većina klasa Vam je dana, tako da ostaje napraviti klase: Transaction, BankAccount i BankException). Osim toga, potrebno je doraditi postojeći kod klase MyList te dodati metodu getCopy, koja vraća kopiju liste. U svim klasama je potrebno implementirati atribute (članske varijable), konstruktore i metode kako su prikazane na dijagramu. Slobodno možete dodati i implementirati dodatne metode, atribute i konstruktore.

Legenda vidljivosti u dijagramu klasa:

Pravila za validaciju koja su dolje navedena ako nisu ispunjena trebaju baciti odgovarajuću iznimku. Klasa BankException je neprovjeravana iznimka. Kod validacija ne trebate pisati točan tekst u iznimkama jer se taj tekst ne provjerava. Svaka klasa treba baciti iznimku specifičnu za tu klasu. Na primjer, ako validacija pravila u klasi BankAccount ne prolazi, potrebno je baciti iznimku BankAccountException.

Klasa IBAN predstavlja broj bankovnog računa. Ugrađena pravila za validaciju su (ovo je dano):

  • IBAN ne smije biti null
  • IBAN mora imati točno 34 znaka
  • IBAN mora sadržavati samo slova i znamenke

Klasa Transaction predstavlja jednu transakciju. Vrsta transakcije je definirana u enumeraciji TransactionType. Postoje 3 tipka transakcije: uplata tj. deposit - uplata na račun (npr. uplata gotovine), isplata tj. withdraw – isplata s računa (npr. korištenjem bankomata) i prijenos tj. transfer – prijenos s jednog računa na drugi račun. Pravila za validaciju transakcije su:

  • amountInHundredths mora biti veći od nule. Primjer iznosa: 100,10 je spremljeno kao vrijednost 10010. U zadatku se isključivo radi s takvim cijelim vrijednostima, pa nije potrebno dodatno pretvaranje.
  • type (vrsta transakcije) ne smije biti null.
  • Barem jedan od sourceAccount ili destinationAccount ne smije biti null.
  • sourceAccount i destinationAccount ne smiju biti isti.
  • Za vrste transakcije WITHDRAWAL ili TRANSFER, sourceAccount ne smije biti null.
  • Za vrste transakcije DEPOSIT ili TRANSFER, destinationAccount ne smije biti null.

U klasi BankAccount se spremaju sve transakcije u listu. Metoda getBalanceInHundredths treba izračunati trenutno stanje tako da prođe kroz sve transakcije. Pretpostavka je da je na početku stanje 0. Pomoću metode addTransaction se dodaju transakcije u listu (pazite na to koje se transakcije smiju dodati). Metoda getTransactions vraća listu koja je kopija internih transakcija. Metode deposit, withdraw i transferTo provjeravaju uvjete i dodaju transakciju u listu (koriste metodu addTransaction). Pravila za validaciju su:

  • IBAN ne smije biti null.
  • Transakcije dodane na račun ne smiju biti null.
  • Transakcije koje se dodaju moraju uključivati ​​IBAN računa koji je ili izvorišni ili odredišni račun.
  • Uplata:
    • Iznos uplate (deposit) mora biti veći od nule.
  • Isplata:
    • Iznos isplate (withdraw) ne smije premašiti stanje na računu.
  • Prijenos (transfer):
    • Iznos prijenosa ne smije premašiti stanje na računu.
    • Transakcija prijenosa se dodaje i izvornom i odredišnom računu.

Napomena: sve klase se nalaze u paketu hr.fer.oop.bank i javne su jedino je klasa MyList paketno privatna.

Primjer korištenja:

package hr.fer.oop.bank;

public class Main {

  public static void main(String[] args) {
    // Create IBANs
    IBAN iban1 = new IBAN("HR12345678901234567890123456789012");
    IBAN iban2 = new IBAN("HR98765432109876543210987654321098");

    // Create Bank Accounts
    BankAccount account1 = new BankAccount(iban1);
    BankAccount account2 = new BankAccount(iban2);

    // Deposit money into account1
    account1.deposit(10000); // Deposit 100.00 in hundredths
    System.out.println("Account 1 balance after deposit: " + account1.getBalanceInHundredths());

    // Withdraw money from account1
    account1.withdraw(5000); // Withdraw 50.00 in hundredths
    System.out.println("Account 1 balance after withdrawal: " + account1.getBalanceInHundredths());

    // Transfer money from account1 to account2
    account1.transferTo(3000, account2); // Transfer 30.00 in hundredths
    System.out.println("Account 1 balance after transfer: " + account1.getBalanceInHundredths());
    System.out.println("Account 2 balance after receiving transfer: " + account2.getBalanceInHundredths());

    // Print transactions for account1
    System.out.println("\nAccount 1 transactions:");
    MyList<Transaction> transactions = account1.getTransactions();
    for (int i = 0; i < transactions.size(); i++) {
      Transaction transaction = transactions.elementAt(i);
      System.out.println(transaction.getType() + " - " + transaction.getAmountInHundredths());
    }

    // Print transactions for account2
    System.out.println("\nAccount 2 transactions:");
    transactions = account2.getTransactions();
    for (int i = 0; i < transactions.size(); i++) {
      Transaction transaction = transactions.elementAt(i);
      System.out.println(transaction.getType() + " - " + transaction.getAmountInHundredths());
    }

    // Some exceptional cases
    System.out.println("\nTesting exceptional cases:");
    System.out.println("Testing invalid IBAN:");
    try {
      new IBAN("INVALID_IBAN"); // Less than 34 characters
    } catch (IbanException e) {
      System.out.println("Exception: " + e);
    }

    System.out.println("Testing invalid transaction:");
    try {
      new Transaction(
        10000,
        TransactionType.DEPOSIT,
        null,
        null
      );
    } catch (TransactionException e) {
      System.out.println("Exception: " + e);
    }

    System.out.println("Testing withdrawal exceeding balance:");
    try {
      account1.withdraw(20000); // Attempt to withdraw more than the balance
    } catch (BankAccountException e) {
      System.out.println("Exception: " + e);
    }

    System.out.println("Testing transfer exceeding balance:");
    try {
      account1.transferTo(20000, account2); // Attempt to transfer more than the balance
    } catch (BankAccountException e) {
      System.out.println("Exception: " + e);
    }
  }
}
