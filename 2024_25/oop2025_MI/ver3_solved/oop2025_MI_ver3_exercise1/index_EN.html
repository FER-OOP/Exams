In the assignment, you need to write the classes as indicated in the class diagram.

All classes and interfaces have visibility set to public and are located in the hr.fer.oop.library package.

In all classes, you also need to implement the methods as shown in the class diagram. The DVD and OnlineArticle classes are given. You are free to add and implement additional methods, attributes, and constructors.

Visibility legend in class diagram:

The class Resource represents the basic resource in the library that has the identifier id, the title title, the author author and the year of publication publicationYear. Implementations of the toString method returns the identifier to which the string ": " is pasted and finally the title. Example: if the identifier is "45" and the title is "Title" then the method returns: "45: Title".

The PhysicalResource class represents a physical resource, e.g. book and has an additional location.

The DigitalResource class represents a digital resource and has an additional format and size.

Physical resources are PhysicalBook and DVD. Each has its own specifics as shown in the UML class diagram.

Digital resources are: EBook and OnlineArticle. Each has its own specifics as shown in the UML class diagram.

The Book interface has a method to retrieve the publisher. All books implement that interface.

The Library class represents a library. In the constructor we have the library name and capacity. The capacity defines the maximum number of resources we can have in the library. Resources can be added and removed from the book (methods addResource and removeResource). The library also has methods for retrieving resources from library:

  • findById finds a resource by id. If there is no such resource, it returns the value null;
  • findInBookTitle finds books by the text in the title. For example, if the title is "Introduction to Java" and the text we send is "java", then that resource should be returned. The method checks that the text we sent as an argument exists in the title, ignoring case. If there are no matching books, return an empty array;
  • getAllResources returns all resources. The array that is returned must not be an internal field, i.e. changing the array that is returned must not change the state of the library. Order is not important. In case there are no resources, return an empty array.

Usage example:

// Create a library with a capacity of 10 resources
Library library = new Library("Computer Library", 10);

// Create different types of resources related to the computer domain
// Add resources to the library
library.addResource(new PhysicalBook(
    "1", "Clean Code", "Robert C. Martin", 2008, "Shelf A", 464, "First Edition", "Prentice Hall"));
library.addResource(new EBook(
    "2", "Python for Data Analysis", "Wes McKinney", 2017, "PDF", 5.2, "O'Reilly Media"));
library.addResource(new DVD(
    "3", "Introduction to Algorithms", "Thomas H. Cormen", 2020, "Shelf B", 180));
library.addResource(new OnlineArticle(
    "4", "Quantum Computing Explained", "John Doe", 2023, "HTML", 0.8, "https://example.com/quantum-computing"));
library.addResource(new OnlineArticle(
    "5", "Namespaces in Python", "Leodanis Pozo Ramos", 2025, "HTML", 1.5,
    "https://realpython.com/python-namespace/"));

// Find a resource by ID
System.out.println(library.findById("3"));
System.out.println(library.findById("10"));

// Search for books with text in the title
Book[] books = library.findInBookTitle("Python");
System.out.println("\nBooks containing 'Python' in the title:");
for (Book book : books) {
  System.out.println("- " + book);
}

// Retrieve all resources in the library
Resource[] allResources = library.getAllResources();
System.out.println("\nAll resources in the library:");
for (Resource resource : allResources) {
  System.out.println("- " + resource.getTitle() + " by " + resource.getAuthor());
}
