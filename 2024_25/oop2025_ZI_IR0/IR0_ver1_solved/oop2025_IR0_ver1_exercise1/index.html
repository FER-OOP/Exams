U stablu direktorija nalaze se datoteke koje sadrže podatke o utakmicama engleske Premier lige. Potrebno je obići stablo direktorija te sakupiti informacije o svim utakmicama iz datoteka koje se nalaze u zadanom direktoriju i svim njegovim poddirektorijima. Pri tome je potrebno odrediti utakmice na kojima je bio prisutan najveći i najmanji broj gledatelje kao i stadione na kojima su odigrane.

Za spremanje podataka o utakmicama imate već gotovu klasu GameInfo koja ima sljedeće javne attribute i metode:

  • week : int - redni broj tjedna u kojem je utakmica odigrana

  • homeTeam : String - domaća momčad

  • awayTeam : String - gostujuća momčad

  • homeGoals : int - broj golova koje je postigla domaća momčad

  • awayGoals : int - broj golova koje je postigla gostujuća momčad

  • venue : String - stadion na kojem je utakmica odigrana

  • attendance : int - broj gledatelja

  • GameInfo createFromString(String line) - statička metoda koja na temelju retka iz datoteke s podacima kreira novi GameInfo objekt

  • String toString() - metoda koja GameInfo objekt pretvara u string

Datoteke s podacima u svakom retku imaju podatke o jednoj utakmici odvojene tabulatorom. Prvi redak sadrži nazive stupaca u datoteci te ga je potrebno preskočiti. Sve ostale retke potrebno je pročitati te na temelju njih kreirati GameInfo objekte koristeći statičku metodu createFromString. Datoteke s podacima možete čitati i sami, bez korištenja klase GameInfo, ali vodite računa da sadrže još neke dodatne podatke koje trebate zanemariti.

Za obilazak stabla direktorija potrebno je napisati Klasu GameFileVisitor koja (izravno ili neizravno) implementira sučelje FileVisitor.

Klasa GameFileVisitor mora implementirati sljedeće javne metode:

  • String getMaxAttVenue() - vraća stadion na kojem je odigrana utakmica s najvećim brojem gledatelja
  • int getMaxAttendance() - vraća najveći broj gledatelja na nekoj od utakmica
  • String getMinAttVenue() - vraća stadion na kojem je odigrana utakmica s najmanjim brojem gledatelja
  • int getMinAttendance() - vraća najmanji broj gledatelja na nekoj od utakmica

Potrebno je i dopuniti klasu MainClass koja je djelomično napisana. Potrebno je napisati statičku metodu

void callVisitor(Path datafolder, FileVisitor<Path> visitor)

u kojoj se pomoću visitora obilazi stablo direktorija i računaju tražene vrijednosti.

Sve klase trebaju biti u paketu hr.fer.oop.

VAŽNO: Za rad s datotekama obavezno koristiti klasu java.nio.file.Path !

VAŽNO: Možete pretpostaviti da u podacima neće biti više od jedne utakmice s najvećim i najmanjim brojem gledatelja.

VAŽNO: U stablu direktorija potrebno je obići sve datoteke neovisno o ektenziji. Možete pretpostaviti da su datoteke ispravno formatirane te da neće doći do pogreške ili iznimke prilikom učitavanja podataka.

Primjer pokretanja:

	Path datafolder = Path.of("src/main/resources/");
	GameFileVisitor visitor = new GameFileVisitor();
	
	callVisitor(datafolder, visitor);
	
	System.out.println("Maximum attendance: " + visitor.getMaxAttVenue() + ": " + visitor.getMaxAttendance());
	System.out.println("Minimum attendance: " + visitor.getMinAttVenue() + ": " + visitor.getMinAttendance());
