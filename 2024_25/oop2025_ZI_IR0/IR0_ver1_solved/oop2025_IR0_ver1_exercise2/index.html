Podaci o utakmicama engleske Premier nogometne lige pohranjeni su u objektima klase GameInfo koja je već napisana i ima sljedeće javne atribute i metode:

  • week : int - broj kola u kojem je utakmica odigrana

  • homeTeam : String - domaća momčad

  • awayTeam : String - gostujuća momčad

  • homeGoals : int - broj golova koje je postigla domaća momčad

  • awayGoals : int - broj golova koje je postigla gostujuća momčad

  • venue : String - stadion na kojem je utakmica odigrana

  • attendance : int - broj gledatelja

  • GameInfo createFromString(String line) - statička metoda koja na temelju retka iz datoteke s podacima kreira novi GameInfo objekt

  • String toString() - metoda koja GameInfo objekt pretvara u string

Statičkom metodom loadGInfData() klase LoadData (također već napisano) podaci se učitavaju u listu.

Potrebno je dopuniti klasu MainClass i napisati kod za četiri statičke metode pomoću Javinih kolekcijskih tokova. Potrebno je napisati sljedeće metode:

  • List<GameInfo> exercise1(Stream<GameInfo> ginfStream) : Metoda prima tok objekata GameInfo i vraća listu utakmica koje je igrala momčad Arsenal (kao domaćin ili kao gost) u kojima je Arsenal postigao 3 ili više golova, dok protivnik u toj utakmici nije postigao niti jedan gol.

  • long exercise2(Stream<GameInfo> ginfStream) : Metoda prima tok objekata GameInfo i vraća najveći broj gledatelja na utakmicama odigranim na stadionu Old Trafford.

  • Stream<GameInfo> exercise3(List<GameInfo> ginfList) : Metoda prima listu objekata GameInfo i vraća tok objekata GameInfo koji sadrži utakmice koje je momčad Tottenham igrala kod kuće sortirane posebnim komparatorom GOAL_COMPARATOR. Pri tome je u klasi MainClass potrebno definirati konačnu i statičku javnu varijablu GOAL_COMPARATOR koja će implementirati sučelje Comparator<GameInfo> i uspoređivat će utakmice prvo prema ukupno postignutom broj golova na utakmici, a zatim prema broju golova koje je postigao domaćin. Npr. utakmica koja je završila 2:0 treba biti ispred utakmice koja je završila 2:2 (zbog ukupnog broja golova), ali nakon utakmice koja je završila 1:1 (zbog jednakog ukupnog broja golova, ali većeg broja golova koje je postigao domaćin). Detaljnije možete vidjeti u primjeru izvođenja. GOAL_COMPARATOR možete implementirati kao lambda izraz ili kao anonimnu klasu.

  • int exercise4(Stream<GameInfo> ginfStream) : Metoda prima tok objekata GameInfo i vraća ukupan broj bodova koje je momčad Liverpool ostvarila kao domaćin. Pri tome vodite računa da pobjeda nosi 3 boda, neriješeni rezultat nosi 1 bod, dok poraz nosi 0 bodova.

Primjer pokretanja:

	// Loading the data
	List<GameInfo> ginfList = LoadData.loadGInfData();
		
	// A list of games played by Arsenal where opponent scored zero goals and Arsenal scored 3 or more 
	List<GameInfo> newList = exercise1(ginfList.stream());
	newList.forEach(System.out::println);
	
	// Maximum attendance at Old Trafford
	long maxatt = exercise2(ginfList.stream());
	
	System.out.print("\nMax attendance at Old Trafford: " + maxatt + "\n\n");
	
	// Stream of Tottenham home Games sorted by GOAL_COMPARATOR
	Stream<GameInfo> ginfStream = exercise3(ginfList);
	ginfStream.limit(5).forEach(ginf -> System.out.println(ginf));
	
	// How many points Liverpool won at home
	int homePointsLiverpool = exercise4(ginfList.stream());
	System.out.println("\nPoints Liverpool won at home: " + homePointsLiverpool);
