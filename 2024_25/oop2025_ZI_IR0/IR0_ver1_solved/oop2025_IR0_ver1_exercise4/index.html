U zadatku je potrebno napisati klase kako je navedeno dijagramom klasa.

U svim klasama je potrebno i implementirati metode kako su prikazane na dijagramu klasa. Slobodno možete dodati i implementirati dodatne metode, atribute i konstruktore.

Sve klase i sučelja imaju vidljivost postavljenu na public i nalaze se u paketu hr.fer.oop.

Legenda vidljivosti u dijagramu klasa:

Potrebno je implementirati sustav za vođenje evidencije zadataka. Sustav se sastoji od klase koja predstavlja pojedinačni zadatak i klase koja upravlja zbirkom svih zadataka, uz odgovarajuću obradu mogućih grešaka putem vlastitih iznimki.

Klasa Task predstavlja jedan zadatak. Svaki zadatak ima id (jedinstveni tekstualni identifikator), description (opis zadatka) te done (logičku vrijednost koja označava je li zadatak izvršen). Metoda markAsDone() postavlja zadatak kao izvršen. U slučaju da je zadatak već bio izvršen, ova metoda baca iznimku TaskAlreadyCompletedException. Metoda toString formatirano ispisuje done, id i description zadatka. Pogledajte primjer ispisa u Main klasi i implementirajte toString() metodu u skladu s prikazanim formatom.

Klasa TaskNotebook predstavlja bilježnicu koja upravlja svim zadacima. Unutar klase, zadaci se pohranjuju u mapi (Map<String, Task>) gdje je ključ identifikator zadatka (id), što osigurava da ne mogu postojati dva zadatka s istim identifikatorom. Klasa definira sljedeće metode:

  • addTask(Task task): Dodaje novi zadatak u bilježnicu. Ako zadatak s istim id-em već postoji, metoda baca iznimku DuplicateTaskException.
  • removeTask(String id): Uklanja zadatak s predanim id-em. Ako zadatak nije pronađen, baca se TaskNotFoundException.
  • completeTask(String id): Označava zadatak s predanim id-em kao izvršen. Ova metoda također može baciti TaskNotFoundException (ako zadatak ne postoji) ili TaskAlreadyCompletedException (ako je zadatak već izvršen).
  • printAllTasks(): Ispisuje sve zadatke iz bilježnice.

Za obradu grešaka, sustav definira hijerarhiju provjeravanih iznimki (checked exceptions):

  • TaskException - apstraktna bazna klasa za sve iznimke vezane uz rukovanje zadacima. Služi kako bi se omogućilo hvatanje svih specifičnih grešaka jednim catch blokom.
  • DuplicateTaskException - nasljeđuje TaskException, a baca se pri pokušaju dodavanja zadatka čiji id već postoji.
  • TaskNotFoundException - nasljeđuje TaskException, a baca se ako se pokuša pristupiti zadatku koji ne postoji u bilježnici.
  • TaskAlreadyCompletedException - nasljeđuje TaskException, a baca se pri pokušaju označavanja već izvršenog zadatka kao ponovno izvršenog.

Sve metode koje mogu uzrokovati grešku (to su metode addTask, removeTask, completeTask) moraju u svom potpisu deklarirati da bacaju odgovarajuće ovdje navedene iznimke.

Primjer korištenja:

public class Main {
    public static void main(String[] args) {
        TaskNotebook notebook = new TaskNotebook();
        
        System.out.println("--- Adding tasks ---");
        try {
            // Creating task instances with the new course names
            notebook.addTask(new Task("ITP", "Write the first homework for Introduction to Programming."));
            notebook.addTask(new Task("MATANA2", "Solve example problems for Mathematical Analysis 2."));
            notebook.addTask(new Task("OOP", "Prepare for the final Object-Oriented Programming exam."));
        } catch (DuplicateTaskException e) {
            System.err.println("Error while adding: " + e.getMessage());
        }

        notebook.printAllTasks();

        System.out.println("\n--- Attempting to add a duplicate task ---");
        try {
            // Attempting to add a task with the same ID
            notebook.addTask(new Task("OOP", "Review the course material for the exam."));
        } catch (DuplicateTaskException e) {
            System.err.println("Error: " + e.getMessage());
        }
        
        System.out.println("\n--- Completing tasks ---");
        try {
            // Marking tasks as completed
            notebook.completeTask("ITP");
            notebook.completeTask("MATANA2");
        } catch (TaskNotFoundException | TaskAlreadyCompletedException e) {
            System.err.println("Error while completing: " + e.getMessage());
        }

        notebook.printAllTasks();

        System.out.println("\n--- Attempting to complete an already completed task ---");
        try {
            // Attempting to complete the same task again
            notebook.completeTask("ITP");
        } catch (TaskNotFoundException | TaskAlreadyCompletedException e) {
            System.err.println("Error: " + e.getMessage());
        }

        System.out.println("\n--- Removing a task ---");
        try {
            // Removing a task from the notebook
            notebook.removeTask("OOP");
            System.out.println("Task 'OOP' was successfully removed.");
            
            notebook.removeTask("MATANA3"); // Attempting to remove a non-existing task
            System.out.println("Task 'MATANA3' was successfully removed."); // This line will not execute
        } catch (TaskNotFoundException e) {
            System.err.println("Error while removing: " + e.getMessage());
        }

        System.out.println("\n--- Final state of the notebook ---");
        notebook.printAllTasks();
    }
}
