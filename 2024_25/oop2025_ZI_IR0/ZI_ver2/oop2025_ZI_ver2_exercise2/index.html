Podaci o utakmicama engleske Premier nogometne lige pohranjeni su u objektima klase GameInfo koja je već napisana i ima sljedeće javne atribute i metode:

  • week : int - broj kola u kojem je utakmica odigrana

  • homeTeam : String - domaća momčad

  • awayTeam : String - gostujuća momčad

  • homeGoals : int - broj golova koje je postigla domaća momčad

  • awayGoals : int - broj golova koje je postigla gostujuća momčad

  • venue : String - stadion na kojem je utakmica odigrana

  • attendance : int - broj gledatelja

  • GameInfo createFromString(String line) - statička metoda koja na temelju retka iz datoteke s podacima kreira novi GameInfo objekt

  • String toString() - metoda koja GameInfo objekt pretvara u string

Statičkom metodom loadGInfData() klase LoadData (također već napisano) podaci se učitavaju u listu.

Potrebno je dopuniti klasu MainClass i napisati kod za četiri statičke metode pomoću Javinih kolekcijskih tokova. Potrebno je napisati sljedeće metode:

  • List<GameInfo> exercise1(Stream<GameInfo> ginfStream) : Metoda prima tok objekata GameInfo i vraća listu utakmica koje je igrala momčad Arsenal (kao domaćin ili kao gost) u kojima je Arsenal pobijedio s 3 ili više golova razlike.

  • Collection<String> exercise2(Stream<GameInfo> ginfStream) : Metoda prima tok objekata GameInfo i vraća kolekciju svih momčadi koje nastupaju u engleskoj Premier ligi. Vraćena kolekcija ne smije sadržavati duplikate.

  • Stream<GameInfo> exercise3(List<GameInfo> ginfList) : Metoda prima listu objekata GameInfo i vraća tok objekata GameInfo koji sadrži utakmice na kojima je ukupno postignuto 7 ili više golova sortirane posebnim komparatorom GAME_COMPARATOR. Pri tome je u klasi MainClass potrebno definirati konačnu i statičku javnu varijablu GAME_COMPARATOR koja će implementirati sučelje Comparator<GameInfo> i uspoređivati utakmice prvo uzlazno prema nazivu domaće momčadi, a zatim silazno prema nazivu gostujuće momčadi. Detaljnije možete vidjeti u primjeru izvođenja. GAME_COMPARATOR možete implementirati kao lambda izraz ili kao anonimnu klasu.

  • int exercise4(Stream<GameInfo> ginfStream, String team) : Metoda prima tok objekata GameInfo i naziv momčadi te vraća ukupnu gol razliku koju je ta momčad ostvarila u svim utakmicama. Gol razliku računate kao: broj_postignutih_golova - broj_primljenih_golova.

NAPOMENA: Ukupnu gol razliku možete izračunati kao sumu gol razlika u pojedinim utakmicama.

Primjer pokretanja:

	// Loading the data
	List<GameInfo> ginfList = LoadData.loadGInfData();
	
	// A list of games that Arsenal won by 3 or more goals (home or away)
	List<GameInfo> newList = exercise1(ginfList.stream());
	newList.forEach(System.out::println);
	
	// A collection of all different teams competing in English premier league
	// without duplicates
	Collection<String> teamCollection = exercise2(ginfList.stream());
	
	System.out.println("\nTeams: ");
	teamCollection.forEach(team -> System.out.print(team + " "));
	System.out.println("\n");
	
	// Stream of Games that had 7 or more total goals scored sorted by GAME_COMPARATOR
	Stream<GameInfo> ginfStream = exercise3(ginfList);
	ginfStream.forEach(ginf -> System.out.println(ginf));
	
	// Goal difference for a given team, just one number (goalsScored - goalsConceded)
	int goalDiff = exercise4(ginfList.stream(), "Liverpool");
	System.out.println("\nGoal difference for Liverpool: " + goalDiff);
