The data about English Premier League matches is stored in objects of the GameInfo class, which has already been implemented and includes the following public attributes and methods:

  • week : int - week in which the game was played

  • homeTeam : String - home team

  • awayTeam : String - away team

  • homeGoals : int - goals scored by the home team

  • awayGoals : int - goals scored by the away team

  • venue : String - a stadium at which the game was played

  • attendance : int - number of spectators

  • GameInfo createFromString(String line) - static method that creates a new GameInfo object from a text line from one of the data files

  • String toString() - a method that returns a String representation of a GameInfo object

Using the static method loadGInfData() from the LoadData class (also already written), the data is loaded into a list.

You need to complete the MainClass and write code for four static methods using Java Stream API (collection streams). You should implement the following methods:

  • List<GameInfo> exercise1(Stream<GameInfo> ginfStream) : This method takes a stream of GameInfo objects and returns a list of matches in which the team Arsenal played (as home or away team), and which Arsenal won by 3 or more goals.

  • Collection<String> exercise2(Stream<GameInfo> ginfStream) : This method takes a stream of GameInfo objects and returns a Collection of all the teams taking part in the Premier League. The returned collection can not contain duplicates.

  • Stream<GameInfo> exercise3(List<GameInfo> ginfList) : This method takes a list of GameInfo objects and returns a stream of matches in which a total of 7 or more goals were scored, sorted using a custom comparator GAME_COMPARATOR. The GAME_COMPARATOR should be declared in the MainClass as a public static final variable implementing Comparator<GameInfo>. It should first sort matches ascending by the home team name, and then descending by the away team name.

You can implement GAME_COMPARATOR using a lambda expression or an anonymous class.

  • int exercise4(Stream<GameInfo> ginfStream, String team) : This method takes a stream of GameInfo objects and a team name and returns the total goal difference for a given team in all the games. The goal difference is calculated as: goals_scored - goals_conceded.

HINT: You can calculate the total goal difference as the summ of goal differences in individual matches.

Execution example:

	// Loading the data
	List<GameInfo> ginfList = LoadData.loadGInfData();
	
	// A list of games that Arsenal won by 3 or more goals (home or away)
	List<GameInfo> newList = exercise1(ginfList.stream());
	newList.forEach(System.out::println);
	
	// A collection of all different teams competing in English premier league
	// without duplicates
	Collection<String> teamCollection = exercise2(ginfList.stream());
	
	System.out.println("\nTeams: ");
	teamCollection.forEach(team -> System.out.print(team + " "));
	System.out.println("\n");
	
	// Stream of Games that had 7 or more total goals scored sorted by GAME_COMPARATOR
	Stream<GameInfo> ginfStream = exercise3(ginfList);
	ginfStream.forEach(ginf -> System.out.println(ginf));
	
	// Goal difference for a given team, just one number (goalsScored - goalsConceded)
	int goalDiff = exercise4(ginfList.stream(), "Liverpool");
	System.out.println("\nGoal difference for Liverpool: " + goalDiff);
