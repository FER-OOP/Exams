The data about English Premier League matches is stored in objects of the GameInfo class, which has already been implemented and includes the following public attributes and methods:

  • week : int - week in which the game was played

  • homeTeam : String - home team

  • awayTeam : String - away team

  • homeGoals : int - goals scored by the home team

  • awayGoals : int - goals scored by the away team

  • venue : String - a stadium at which the game was played

  • attendance : int - numbed of spectators

  • GameInfo createFromString(String line) - static method that creates a new GameInfo object from a text line from one of the data files

  • String toString() - a method that return a String representation of a GameInfo object

Using the static method loadGInfData() from the LoadData class (also already written), the data is loaded into a list.

You need to complete the MainClass and write code for four static methods using Java Stream API (collection streams). You should implement the following methods:

  • List<GameInfo> exercise1(Stream<GameInfo> ginfStream) : This method takes a stream of GameInfo objects and returns a list of matches in which the team Arsenal played (as home or away team), where Arsenal scored 3 or more goals, and the opponent scored 0 goals.

  • long exercise2(Stream<GameInfo> ginfStream) : This method takes a stream of GameInfo objects and returns the maximum number of spectators for matches played at the stadium Old Trafford.

  • Stream<GameInfo> exercise3(List<GameInfo> ginfList) : This method takes a list of GameInfo objects and returns a stream of matches played by Tottenham as the home team, sorted using a custom comparator GOAL_COMPARATOR. The GOAL_COMPARATOR should be declared in the MainClass as a public static final variable implementing Comparator<GameInfo>. It should sort matches first, by total goals scored in the match (ascending), then, by goals scored by the home team (ascending).

Example: A match that ended 2–0 comes before 2–2 (fewer total goals), but after a 1–1 match (same total, but more home goals).

You can implement GOAL_COMPARATOR using a lambda expression or an anonymous class.

  • int exercise4(Stream<GameInfo> ginfStream) : This method takes a stream of GameInfo objects and returns the total number of points won by Liverpool when playing at home. Wining a match equals 3 points, draw equals 1 point and a loss equals 0 points.

Execution example:

	// Loading the data
	List<GameInfo> ginfList = LoadData.loadGInfData();
		
	// A list of games played by Arsenal where opponent scored zero goals and Arsenal scored 3 or more 
	List<GameInfo> newList = exercise1(ginfList.stream());
	newList.forEach(System.out::println);
	
	// Maximum attendance at Old Trafford
	long maxatt = exercise2(ginfList.stream());
	
	System.out.print("\nMax attendance at Old Trafford: " + maxatt + "\n\n");
	
	// Stream of Tottenham home Games sorted by GOAL_COMPARATOR
	Stream<GameInfo> ginfStream = exercise3(ginfList);
	ginfStream.limit(5).forEach(ginf -> System.out.println(ginf));
	
	// How many points Liverpool won at home
	int homePointsLiverpool = exercise4(ginfList.stream());
	System.out.println("\nPoints Liverpool won at home: " + homePointsLiverpool);
