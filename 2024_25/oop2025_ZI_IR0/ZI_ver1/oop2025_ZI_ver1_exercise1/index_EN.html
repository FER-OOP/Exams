A directory tree contains files with data on games in English Premier League. You need to traverse the directory tree and collect the data on all games to find out the games with the largest and the smallest attendance, as well as the venues at which they were played.

To store data on specific games, you can use an available class GameInfo with following public attributes and methods:

  • week : int - week in which the game was played

  • homeTeam : String - home team

  • awayTeam : String - away team

  • homeGoals : int - goals scored by the home team

  • awayGoals : int - goals scored by the away team

  • venue : String - a stadium at which the game was played

  • attendance : int - number of spectators

  • GameInfo createFromString(String line) - static method that creates a new GameInfo object from a text line from one of the data files

  • String toString() - a method that returns a String representation of a GameInfo object

Data files contain data for one game in each row, delimited with a tabulator. The first line contains column names and should be skipped. All other lines should be read and used to create GameInfo objects using the static method createFromString. You can read data files in your own way without using GameInfo class, but keep in mind that they contain additional data that needs to be ignored.

To traverse the directory tree you need to write a class GameFileVisitor that (directly or indirectly) implements the FileVisitor interface.

Class GameFileVisitor needs to implement the following public methods:

  • String getMaxAttVenue() - returns the venue (stadium) on which the game with the largest attendance was played
  • int getMaxAttendance() - returns the largest attendance in any game
  • String getMinAttVenue() - returns the venue (stadium) on which the game with the smallest attendance was played
  • int getMinAttendance() - returns the smallest attendance in any game

You also need to complete the class MainClass that is partially written. You need to write the code for the static method

void callVisitor(Path datafolder, FileVisitor<Path> visitor)

that uses the visitor to traverse the directory tree and to calculate the required values.

All classes must be placed in the package hr.fer.oop.

IMPORTANT: When working with files use class java.nio.file.Path !

IMPORTANT: You can assume that only one game will have the highest attendance and that only one game will have the lowest attendance.

IMPORTANT: You need to read all the files in the directory tree, regardless of the extension. You can also assume that all the files are correctly formated and that loading the data will not cause unexpected errors or exceptions.

Execution example:

	Path datafolder = Path.of("src/main/resources/");
	GameFileVisitor visitor = new GameFileVisitor();
	
	callVisitor(datafolder, visitor);
	
	System.out.println("Maximum attendance: " + visitor.getMaxAttVenue() + ": " + visitor.getMaxAttendance());
	System.out.println("Minimum attendance: " + visitor.getMinAttVenue() + ": " + visitor.getMinAttendance());

Expected output:
