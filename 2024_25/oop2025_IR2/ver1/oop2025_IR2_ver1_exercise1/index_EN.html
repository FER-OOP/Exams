You are required to implement a simple system for managing the library's multimedia collection. The system must support different types of materials, such as books, magazines, and DVDs.

The abstract generic class Content<T> represents the basic unit of content in the library. Each building unit has a unique id, title and data whose type is defined by the generic parameter T. The class also defines an abstract describeContent() method that concrete subclasses must implement to provide a specific description of their content (eg text summary, media duration). In addition, it also implements a concrete getDescription() method that returns a formatted printout with an ID, name and specific description.

There are three concrete types of construction:

  • Book - represents a specific book. It inherits the parameterized class Content. The data (data) is of type String, and the method describeContent() returns the first 30 characters of the text. If the text is longer than 30 characters, then the method describeContent() takes only the first 30 characters of the text and adds three dots "..." at the end. In case the text is empty, the method describeContent() returns an empty string.
  • DVD - represents a specific DVD. It also inherits the parameterized Content class. The data (data) is of type Integer and indicates the duration in minutes, and the describeContent() method implemented in the class DVD returns a description of the duration, e.g. "Duration: 55 minutes".
  • Magazine - represents a magazine. Same as Book inherits parameterized class Content. Also, just like in Book, the data (data) is of type String, and the describeContent() method returns the first 30 characters of the text. If the text is longer than 30 characters, then the method takes only the first 30 characters of the text and adds three periods "..." to the end. In case the text is empty, the method describeContent() returns an empty string. But, unlike Book, class Magazine can optionally contain a DVD as an additional attachment (the supplementDVD data). If it does not contain one, then the value of this data is null. If Magazine does contain a supplemental DVD then the getDescription() in Magazine as an output returns description of the super class, adds string "\n + Includes: " and adds description of the supplementDVD data.

See the expected output for an example of using these two methods.

Finally, the MediaCollection class represents the collection of all media itself. It contains a list of all the items of content (List<Content<?>>). By using wildcards, the library can store different types of content (Book, DVD and Magazine) at the same time. The class provides several public methods: a method for adding new content (addItem), a method retrieving content by a generic type (getItemsOfTheSameTypeAsObject, e.g. Book, DVD or Magazine), a method for retrieval of the whole collection of all media (getAllItems), and a method for printing descriptions of all content (printAllDescriptions). Ensure that changes to the returned list will not affect the content stored in the collection of all media.

Usage example:

public class Main {
    public static void main(String[] args) {
        // Create a MediaCollection instance
        MediaCollection collection = new MediaCollection();
        
		// Adding books to the collection
        Book book1 = new Book("B-001", "The Hobbit", "In a hole in the ground there lived a hobbit.");
        Book book2 = new Book("B-002", "A Brief History of Time", "Popular-science book.");
        collection.addItem(book1);
        collection.addItem(book2);
        
        // Adding DVDs to the collection
        DVD dvd1 = new DVD("D-001", "The Lord of the Rings: The Fellowship of the Ring", 178);
        DVD dvd2 = new DVD("D-002", "The Lord of the Rings: The Two Towers", 179);
        collection.addItem(dvd1);
        collection.addItem(dvd2);
        
        // Adding magazines to the collection
        Magazine magazine1 = new Magazine("M-001", "National Geographic - May 2024", "A Journey to Mars.");
        collection.addItem(magazine1);
        
        // Adding a DVD supplement to the magazine
        DVD supplement = new DVD("S-001", "Documentary: Volcanoes", 55);
        collection.addItem(new Magazine("M-002", "PC Gamer - June 2025", "Exclusive previews, reviews of latest hardware for gaming.", supplement));

        // Print the descriptions of all items in the collection
        System.out.println("Description of all items in the collection:");
        collection.printAllDescriptions();

        // Retrieving and printing only the books
        System.out.println("\nOnly books in the collection:");        
        for (Book b : collection.getItemsOfTheSameTypeAsObject(book1)) { // Using book1 as a type reference
            System.out.println(b.getDescription());
        }

        // Retrieving and printing only the magazines
        System.out.println("\nOnly magazines in the collection:");
        for (Magazine m : collection.getItemsOfTheSameTypeAsObject(magazine1)) { // Using magazine1 as a type reference
            System.out.println(m.getDescription());
        }
    }
}
