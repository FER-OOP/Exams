In the directory tree, there are zip files containing learning materials for different courses. All materials for a course are stored in a single zip archive file (for example, the file oop.zip contains several PDFs with practice exercises, TXT files with tips, PPT lecture presentations, screenshots of Eclipse errors in JPG format, etc.).

It is necessary to traverse the directory tree and collect information about all available materials from all courses, so that after the traversal it is possible to retrieve the data requested later in the task.

For traversing the directory tree, you need to write a class MaterialsFileVisitor which (directly or indirectly) implements the FileVisitor interface.

The MaterialsFileVisitor class must implement the following public methods:

  • int getTotalMaterialCount() - returns the total number of materials (files) in all zip archives

  • String getBiggestFileName() - returns the name of the largest file among all materials (the largest file is the one that, when uncompressed, occupies the most bytes)

  • int getPdfCount(String zipFileName) - returns the total number of PDF files found in the zip archive of a specific course

  • int getCourseMaterialUncompressedSize(String zipFileName) - returns the sum of uncompressed sizes of all files of the given course (i.e., inside a given zip archive file)

  • int getCourseMaterialCompressedSize(String zipFileName) - returns the sum of compressed sizes of all files of the given course (i.e., inside a given zip archive file)

All classes must be in the package hr.fer.oop.

IMPORTANT: When working with files, you must use the class java.nio.file.Path!

You may use the provided class Material for help, but you don't have to. Each instance of this class represents a single learning material, i.e., a file. For example, “01-Uvod.pdf” is one material and is located—together with several other materials — in the “asp.zip” archive.

For working with zip files, you can use the classes ZipFile and ZipFileEntry, and for the traversal of all files ("ZipFileEntries") within a single zip archive the easiest way is using the Stream API methods, e.g. "zipFile.stream().forEach(entry -> {...}".

Example of execution:

    Path folder = Path.of("src/main/resources/");
    MaterialsFileVisitor visitor = new MaterialsFileVisitor();
    
    try {
        Files.walkFileTree(folder, visitor);
    } catch (IOException e)             
        e.printStackTrace();
    }
    
    System.out.println("Total material count: " + visitor.getTotalMaterialCount());
    System.out.println("The biggest file: " + visitor.getBiggestFileName());
    System.out.println("PDF count for OOP.zip: " + visitor.getPdfCount("OOP.zip"));
    System.out.println("Size of the uncompressed zip file: " + visitor.getCourseMaterialUncompressedSize("OOP.zip"));
    System.out.println("Size of the compressed zip file: " + visitor.getCourseMaterialCompressedSize("OOP.zip"));
