U stablu direktorija nalaze se zip datoteke koje sadrže materijale za učenje različitih predmeta. Svi materijali iz nekog predmeta su spremljeni u jednu zip arhivu (tako npr. datoteka oop.zip sadrži nekoliko materijala - pdf-ove sa zadacima za vježbu, txt datoteke sa savjetima, ppt prezentacije s predavanja, screenshotove pogrešaka u Eclipse u jpg formatu i sl.)

Potrebno je obići stablo direktorija te sakupiti informacije o svim dostupnim materijalima iz svih predmeta, i to tako da je nakon obilaska stabla moguće dobiti podatke koji se traže niže u zadatku.

Za obilazak stabla direktorija potrebno je napisati Klasu MaterialsFileVisitor koja (izravno ili neizravno) implementira sučelje FileVisitor. Klasa MaterialsFileVisitor mora implementirati sljedeće javne metode:

  • int getTotalMaterialCount() - vraća ukupni broj materijala (datoteka) u svim zip arhivama zajedno

  • String getBiggestFileName() - vraća naziv najveće datoteke materijala (najveća datoteka je ona koja nekompresirana zauzima najviše okteta, tj. "byteova")

  • int getPdfCount(String zipFileName) - vraća ukupni broj PDF datoteka pronađenih u materijalima nekog predmeta

  • int getCourseMaterialUncompressedSize(String zipFileName) - vraća sumu nekompresiranih veličina svih datoteka zadanog predmeta (tj. unutar neke zip arhive)

  • int getCourseMaterialCompressedSize(String zipFileName) - vraća sumu kompresiranih veličina svih datoteka zadanog predmeta (tj. unutar neke zip arhive)

Sve klase trebaju biti u paketu hr.fer.oop.

VAŽNO: Za rad s datotekama obavezno koristiti klasu java.nio.file.Path !

Kao pomoć možete koristiti priloženu klasu Material, ali i ne morate. Svaka instanca ove klase predstavlja jedan materijal za učenje, tj. datoteku, npr. "01-Uvod.pdf" je jedan materijal, nalazi se (zajedno s još nekoliko drugih materijala) u zip arhivi "asp.zip".

Za rad sa zip arhivama možete koristiti klase ZipFile i ZipFileEntry, a obilazak svih datoteka("ZipFileEntries") unutar jedne zip arhive najlakše je obaviti koristeći metode Stream API-ja, npr. "zipFile.stream().forEach(entry -> {...}"

Primjer pokretanja:

	Path folder = Path.of("src/main/resources/");
	MaterialsFileVisitor visitor = new MaterialsFileVisitor();
	
	try {
		Files.walkFileTree(folder, visitor);
	} catch (IOException e) {			
		e.printStackTrace();
	}

	System.out.println("Total material count: " + visitor.getTotalMaterialCount();
	System.out.println("The biggest file: " + visitor.getBiggestFileName();
	System.out.println("PDF count for OOP.zip: " + visitor.getPdfCount("OOP.zip");
	System.out.println("Size of the uncompressed zip file: " + visitor.getCourseMaterialUncompressedSize("OOP.zip");
	System.out.println("Size of the compressed zip file: " + visitor.getCourseMaterialCompresedSize("OOP.zip");
