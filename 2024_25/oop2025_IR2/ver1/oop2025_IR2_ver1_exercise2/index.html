U zadatku je potrebno napisati klase kako je navedeno dijagramom klasa.

U svim klasama je potrebno i implementirati metode kako su prikazane na dijagramu klasa. Slobodno možete dodati i implementirati dodatne metode, atribute i konstruktore.

Sve klase i sučelja imaju vidljivost postavljenu na public i nalaze se u paketu hr.fer.oop.

Legenda vidljivosti u dijagramu klasa:

Potrebno je implementirati sustav za upravljanje portfeljem projekata. Sustav se sastoji od klase koja predstavlja pojedinačni projekt i klase koja upravlja zbirkom svih projekata, uz odgovarajuću obradu mogućih grešaka putem hijerarhije vlastitih iznimki.

Klasa Project predstavlja jedan projekt. Svaki projekt ima id (jedinstveni tekstualni identifikator), description (opis projekta), 'priority' (prioritet projekta, vrijednost enumeracije 'ProjectPriority') te done (logičku vrijednost koja označava je li projekt dovršen). Metoda markAsDone() postavlja projekt kao dovršen. U slučaju da je projekt već bio dovršen, ova metoda baca iznimku ProjectAlreadyCompletedException.

Enumeracija 'ProjectPriority' definira tri diskretne vrijednosti: LOW, NORMAL, HIGH.

Klasa ProjectManager predstavlja upravitelja koji rukuje svim projektima u portfelju. Unutar klase, projekti se pohranjuju u mapi (Map<String, Project>) gdje je ključ identifikator projekta (id), što osigurava da ne mogu postojati dva projekta s istim identifikatorom. Klasa definira sljedeće metode:

  • addProject(Project project): Dodaje novi projekt u portfelj. Ako projekt s istim id-em već postoji, metoda baca iznimku DuplicateProjectException.
  • removeProject(String id): Uklanja projekt s predanim id-em. Ako projekt nije pronađen, baca se ProjectNotFoundException.
  • completeProject(String id): Označava projekt s predanim id-em kao dovršen. Ova metoda također može baciti ProjectNotFoundException (ako projekt ne postoji) ili ProjectAlreadyCompletedException (ako je projekt već dovršen).
  • printAllProjects(): Ispisuje sve projekte iz portfelja.

Za obradu grešaka, sustav definira hijerarhiju provjeravanih iznimki (checked exceptions):

  • ProjectException - bazna klasa za sve iznimke vezane uz rukovanje projektima. Služi kako bi se omogućilo hvatanje svih specifičnih grešaka jednim catch blokom.
  • DuplicateProjectException - nasljeđuje ProjectException, a baca se pri pokušaju dodavanja projekta čiji id već postoji.
  • ProjectNotFoundException - nasljeđuje ProjectException, a baca se ako se pokuša pristupiti projektu koji ne postoji u portfelju.
  • ProjectAlreadyCompletedException - nasljeđuje ProjectException, a baca se pri pokušaju označavanja već dovršenog projekta kao ponovno dovršenog.

Sve metode koje mogu uzrokovati grešku (addProject, removeProject, completeProject) moraju u svom potpisu deklarirati da bacaju odgovarajuće ovdje navedene iznimke.

Primjer korištenja:

public class Main {
    public static void main(String[] args) {
        ProjectManager manager = new ProjectManager();

        System.out.println("--- 1. Adding initial projects ---");
        try {
			manager.addProject(new Project("WEB-APP", "Development of a new web application for a client.", ProjectPriority.NORMAL));
            manager.addProject(new Project("MOBILE-GAME", "Creation of a mobile game for Android and iOS.", ProjectPriority.LOW));
            manager.addProject(new Project("AI-RESEARCH", "Researching new AI models for language processing.", ProjectPriority.HIGH));
        } catch (ProjectException e) {
            System.err.println("Error during initialization: " + e.getMessage());
        }
        manager.printAllProjects();

        System.out.println("\n--- 2. Attempting to add a project with a duplicate ID ---");
        try {
            manager.addProject(new Project("WEB-APP", "Upgrading the existing web application.", ProjectPriority.NORMAL));
        } catch (ProjectException e) {
            System.err.println("Expected error: " + e.getMessage());
        }

        System.out.println("\n--- 3. Marking a project as complete ---");
        try {
            manager.completeProject("MOBILE-GAME");
        } catch (ProjectException e) {
            System.err.println("Error: " + e.getMessage());
        }
        System.out.println("State after completing a project:");
        manager.printAllProjects();

        System.out.println("\n--- 4. Attempting to remove a non-existent project ---");
        try {
            manager.removeProject("DATA-ANALYSIS");
        } catch (ProjectException e) {
            System.err.println("Expected error: " + e.getMessage());
        }

        System.out.println("\n--- 5. Final state of the project portfolio ---");
        manager.printAllProjects();
    }
}
