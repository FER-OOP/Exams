U zadatku je potrebno napisati klase kako je navedeno dijagramom klasa.

U svim klasama je potrebno i implementirati metode kako su prikazane na dijagramu klasa. Slobodno možete dodati i implementirati dodatne metode, atribute i konstruktore.

Sve klase i sučelja imaju vidljivost postavljenu na public i nalaze se u paketu hr.fer.oop.

Legenda vidljivosti u dijagramu klasa:

Potrebno je implementirati jednostavan sustav za upravljanje kolekcijom multimedijskih zapisa u knjižnici. Sustav mora podržavati različite vrste građe, kao što su knjige, časopisi i DVD-ovi.

Apstraktna generička klasa Content<T> predstavlja temeljnu jedinicu građe u knjižnici. Svaka jedinica građe ima jedinstveni id, title (naziv) i data (podatke) čiji je tip definiran generičkim parametrom T. Klasa također definira apstraktnu metodu describeContent() koju konkretne podklase moraju implementirati kako bi pružile specifičan opis svog sadržaja (npr. sažetak teksta, trajanje medija). Pored toga, implementira i konkretnu metodu getDescription() koja vraća formatirani ispis s ID-em, nazivom i specifičnim opisom.

Postoje tri konkretne vrste građe:

  • Book - predstavlja konkretnu knjigu. Nasljeđuje parametriziranu klasu Content. Podatak (data) je tipa String, a metoda describeContent() vraća prvih 30 znakova teksta. Ako je tekst duži od 30 znakova onda metoda uzima samo prvih 30 znakova teksta i na kraj dodaje tri točke "...". U slučaju da je tekst prazan, metoda describeContent() vraća prazan niz znakova.
  • DVD - predstavlja konkretan DVD. Također nasljeđuje parametriziranu klasu Content. Podatak (data) je tipa Integer i označava trajanje u minutama, a metoda describeContent() vraća opis trajanja, npr. "Duration: 55 minutes".
  • Magazine - predstavlja časopis. Isto kao Book nasljeđuje parametriziranu klasu Content. Također, isto kao u Book podatak (data) je tipa String, a metoda describeContent() vraća prvih 30 znakova teksta. Ako je tekst duži od 30 znakova onda metoda uzima samo prvih 30 znakova teksta i na kraj dodaje tri točke "...". U slučaju da je tekst prazan, metoda describeContent() vraća prazan niz znakova. Ali, za razliku od Book, Magazine opcionalno može sadržavati DVD kao dodatni prilog (podatak supplementDVD). Ako ne sadržava, onda je vrijednost ovog podatka null. Ako Magazine sadrži dodatni DVD, tada getDescription() u Magazine kao izlaz vraća opis nadklase, dodaje niz "\n + Includes: " i dodaje opis podataka supplementDVD.

Pogledati očekivani ispis za primjer uporabe ove dvije metode.

Konačno, klasa MediaCollection predstavlja samu kolekciju svih medija. Ona sadrži listu svih jedinica građe (List<Content<?>>). Korištenjem zamjenskog znaka (wildcard), knjižnica može istovremeno pohraniti različite vrste građe (Book, DVD i Magazine). Klasa nudi nekoliko javnih metoda: metodu za dodavanje nove građe (addItem), metodu za dohvaćanje građe po generičkom tipu (getItemsOfTheSameTypeAsObject, npr. Book, DVD ili Magazine), metodu za dohvaćanje cijele kolekcije svih medija (getAllItems), te metodu za ispisivanje opisa cjelokupne građe (printAllDescriptions). Osigurati da promjene na vraćenoj listi neće imati utjecaja na građu pohranjenu u kolekciji svih medija.

Primjer korištenja:

public class Main {
    public static void main(String[] args) {
        // Create a MediaCollection instance
        MediaCollection collection = new MediaCollection();
        
		// Adding books to the collection
        Book book1 = new Book("B-001", "The Hobbit", "In a hole in the ground there lived a hobbit.");
        Book book2 = new Book("B-002", "A Brief History of Time", "Popular-science book.");
        collection.addItem(book1);
        collection.addItem(book2);
        
        // Adding DVDs to the collection
        DVD dvd1 = new DVD("D-001", "The Lord of the Rings: The Fellowship of the Ring", 178);
        DVD dvd2 = new DVD("D-002", "The Lord of the Rings: The Two Towers", 179);
        collection.addItem(dvd1);
        collection.addItem(dvd2);
        
        // Adding magazines to the collection
        Magazine magazine1 = new Magazine("M-001", "National Geographic - May 2024", "A Journey to Mars.");
        collection.addItem(magazine1);
        
        // Adding a DVD supplement to the magazine
        DVD supplement = new DVD("S-001", "Documentary: Volcanoes", 55);
        collection.addItem(new Magazine("M-002", "PC Gamer - June 2025", "Exclusive previews, reviews of latest hardware for gaming.", supplement));

        // Print the descriptions of all items in the collection
        System.out.println("Description of all items in the collection:");
        collection.printAllDescriptions();

        // Retrieving and printing only the books
        System.out.println("\nOnly books in the collection:");        
        for (Book b : collection.getItemsOfTheSameTypeAsObject(book1)) { // Using book1 as a type reference
            System.out.println(b.getDescription());
        }

        // Retrieving and printing only the magazines
        System.out.println("\nOnly magazines in the collection:");
        for (Magazine m : collection.getItemsOfTheSameTypeAsObject(magazine1)) { // Using magazine1 as a type reference
            System.out.println(m.getDescription());
        }
    }
}
