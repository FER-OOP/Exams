U datoteci match_results.csv nalaze se podaci o igračima koji su sudjelovali na online turnirima u jednoj poznatoj računalnoj igri.

Svaki redak datoteke sadrži sljedeće podatke:

godina; ime igrača; bodovi; broj pobjeda; mapa

npr. izrezak iz datoteke

2025;WittyOstrich;12;2;Tilted
2025;Vioxid;17;3;Gun game
2025;Dr0nai;2;0;Gun game

kaže kako je WittyOstrich na mapi "Tilted" u 2025. godini skupio 12 bodova, uz 2 pobjede, dok su u istoj godini na mapi "Gun game" Vioxid i Dr0nai osvojili, 17, odnosno 2 boda.

Radi jednostavnosti, podaci su pohranjeni u kolekciju objekata tipa PlayerResult koja sadrži informacije o igraču (int godina, String playerName, int points, int wins, String mapName).

Vaš zadatak je, koristeći Java Stream API, implementirati sljedeće metode:

  • long getNumberOfMapsInAYear(Stream<PlayerResult> s, int year) - vraća broj različitih mapa koje su igrane u nekoj godini

  • int getWinsInAYear(Stream<PlayerResult> s, int year, String playerName) - za nekog igrača i godinu, vraća ukupni broj pobjeda tog igrača u zadanoj godini

  • int getMostPointsInAYear(Stream<PlayerResult> s, int year) - vraća najviše bodova koje je neki (bilo koji) igrač skupio u zadanoj godini. Zadatak možete riješiti pomoću Collectors.groupingBy ili npr. koristeći nekoliko naredbi, pomoćnu mapu i metodu merge za punjenje pomoćne mape s podacima.

  • List<String> getPlayerWithMaxWins(Collection<PlayerResult> c, int year, String mapName) - vraća listu koja sadrži ime jednog ili više igrača koji su skupili najviše pobjeda u nekoj godini, na nekoj mapi.

Primjer pokretanja:

	System.out.println("Number of different maps played in a 2024: " + getNumberOfMapsInAYear(list.stream(), 2024));
	System.out.println("Number of wins for WittyOstrich in a 2025: " + getWinsInAYear(list.stream(), 2025, "WittyOstrich"));
	System.out.println("Most points in a 2022: " + getMostPointsInAYear(list.stream(), 2022));
	System.out.println("Players with most wins in 2024: " + getPlayerWithMaxWins(list, 2025, "Zone wars"));
