The file match_results.csv contains data about players who participated in online tournaments in a popular computer game.

Each row of the file contains the following data:

year; player name; points; number of wins; map

e.g., a snippet from the file

2025;WittyOstrich;12;2;Tilted
2025;Vioxid;17;3;Gun game
2025;Dr0nai;2;0;Gun game

says that WittyOstrich on the “Tilted” map in 2025 collected 12 points with 2 wins, while in the same year on the “Gun game” map Vioxid and Dr0nai scored 17 and 2 points, respectively.

For simplicity, the data are stored in a collection of PlayerResult objects that contain information about the player (int year, String playerName, int points, int wins, String mapName).

Your task is, using the Java Stream API, to implement the following methods:

  • long getNumberOfMapsInAYear(Stream<PlayerResult> s, int year) – returns the number of distinct maps that were played in a given year

  • int getWinsInAYear(Stream<PlayerResult> s, int year, String playerName) – for a given player and year, returns that player’s total number of wins in the specified year

  • int getMostPointsInAYear(Stream<PlayerResult> s, int year) – returns the highest number of points that any player accumulated in the given year. You can solve this using Collectors.groupingBy or, for example, by using a few statements, an auxiliary map, and the merge method to populate the auxiliary map with data.

  • List<String> getPlayerWithMaxWins(Collection<PlayerResult> c, int year, String mapName) – returns a list containing the name(s) of the player(s) who collected the most wins in a given year on a given map.

Example run:

	System.out.println("Number of different maps played in a 2024: " + getNumberOfMapsInAYear(list.stream(), 2024));
	System.out.println("Number of wins for WittyOstrich in a 2025: " + getWinsInAYear(list.stream(), 2025, "WittyOstrich"));
	System.out.println("Most points in a 2022: " + getMostPointsInAYear(list.stream(), 2022));
	System.out.println("Players with most wins in 2024: " + getPlayerWithMaxWins(list, 2025, "Zone wars"));

Expected output for the sample test:

Number of different maps played in a 2024: 3
Number of wins for WittyOstrich in a 2025: 4
Most points in a 2022: 28
Players with most wins in 2024: [Vioxid, WittyOstrich]
